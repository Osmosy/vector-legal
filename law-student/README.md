# Law Student — Помощник студента-юриста (Vector Legal)

Адаптация [claude-for-legal/law-student](https://github.com/anthropics/claude-for-legal)
(Anthropic, Apache-2.0) под систему российского юридического образования.

## ⚠️ LEARNING MODE, NOT ANSWER MODE — главный принцип плагина

**Каждый выход — учебный каркас, а не готовый ответ. Плагин структурирует ваше
мышление, тренрует Socratically и указывает на ошибки. Он НЕ пишет конспект,
брифинг, сочинение и не даёт готовых ответов — это убило бы смысл обучения.**

- **socratic-drill, case-brief (в режиме drill-me), cold-call-prep, irac-practice,
  legal-writing** намеренно построены так, чтобы НЕ давать ответ и не писать за
  вас. Учитесь, делая. Если нужен готовый ответ — это инструмент другого сорта.
- **legal-writing — самый строгий.** Читает ваш черновик, говорит, что слабо, но
  никогда не переписывает. Просьба «перепиши» → вежливый отказ + предложение
  более точной структурной критики. Это фича, не баг.
- **outline-builder и case-brief следуют тому же правилу в мягкой форме:**
  каркас — да, наполнение — только из ваших материалов и источников.
  Если вставлен текст судебного акта, навык извлекает в ячейки собственную
  формулировку суда — это указание на источник, а не «написать за вас».
- **Socratic-навык задаёт вопросы ВАМ, отклоняет халтуру и никогда не пишет
  за студента** — это принцип, перенесённый из CFL без изменений.

## Кому

Студенты юридических вузов и факультетов (бакалавриат, специалитет,
магистратура), выпускники, готовящиеся к **экзамену на статус адвоката**
(гл. 2-3 ФЗ-63 «Об адвокатской деятельности…» — письменный этап: тестовые
вопросы + сочинение/решение казусов), стажёры, junior-юристы.

## Первый запуск: cold-start

Этот навык о вас, а не об организации. Ваши курсы, семестры, формат
выпускного экзамена / экзамена на статус, стиль обучения — «тренируй меня»
или «объясни мне». Приносите материалы: прошлые конспекты, проверенные
работы, старые экзаменационные билеты (особенно тех же преподавателей),
базы тестовых вопросов, программы курсов. Цель — 10–20 материалов; меньше
десяти → профиль получает флаг `LIMITED DATA`, и выходы навыков будут
тоньше, пока материалов не добавится.

```
/law-student:cold-start-interview
```

## Навыки

Каждый навык вызывается как `/law-student:<skill-name>`.

| Навык | Что делает |
|---|---|
| `/law-student:cold-start-interview` | Интервью «о тебе» + приём материалов — курсы, экзамен, стиль обучения, материалы |
| `/law-student:socratic-drill [тема]` | Socratic-тренажёр — он спрашивает, вы отвечаете, он отклоняет халтуру. Не даёт ответ. |
| `/law-student:case-brief [дело]` | Конспект судебного акта (КС РФ / ВС РФ / арбитраж) в вашем формате |
| `/law-student:outline-builder [предмет]` | Построить или дополнить опорный конспект в вашем формате из материалов курса |
| `/law-student:bar-prep-questions [предмет]` | Вопросы формата экзамена на статус адвоката (тестовая часть / сочинение по ФЗ-63 гл. 2-3) или магистратуры — с учётом юрисдикции РФ, помечает базовые правила против специальных (напр., арбитражная специфика по АПК) |
| `/law-student:flashcards [предмет]` | Генерация и тренаж флеш-карточек; ящики Лейтнера; per-subject markdown; режим `--session <n>` |
| `/law-student:study-plan` | Долгосрочный учебный план по семестрам РФ — фазы, предметы по слабостям, адаптивное расписание из истории сессий |
| `/law-student:session <предмет> <n>` | Сфокусированная сессия из N вопросов по предмету; обновляет план результатами |
| `/law-student:irac-practice` | Оценка вашего сочинения по IRAC (I–Правовая проблема [фабула→вопрос], R–Правовое обоснование [норма], A–Анализ-применение, C–Вывод): структура, проблемы, нормы, анализ. Никогда не переписывает. |
| `/law-student:cold-call-prep [дело]` | Подготовка к опросу на семинаре — предсказать вопросы преподавателя и натренировать их |
| `/law-student:legal-writing [путь-или-текст]` | Структурная обратная связь по черновику судебного документа (исковое / апелляция по АПК/ГПК) — никогда не переписывает |
| `/law-student:exam-forecast [курс]` | Анализ прошлых билетов того же преподавателя; прогноз ближайшего экзамена |

## Что значит learning mode

Несколько навыков (socratic-drill, case-brief в режиме drill-me,
cold-call-prep, irac-practice, legal-writing) намеренно построены, чтобы
*не* давать ответ и не писать за вас. Смысл — вы учитесь, делая. Если нужен
готовый ответ или черновик — инструмент другой. Этот плагин — про борьбу,
которая и есть учёба.

## Академическая честность

Прежде чем использовать плагин для оцениваемой работы (контрольные,
домашние, курсовые, ВКР, письменные экзамены), проверьте правила вашей
«вШУ» — положения программы о самостоятельности работ и правила вашего
преподавателя об ИИ. Плагин построен для учёбы и тренировки; использовать
его там, где запрещено, — нарушение академической этики, и последствия —
ваши. При сомнениях спросите преподавателя письменно.

Навыки learning mode намеренно не дают готовых ответов — это и педагогика,
и дизайн-предпосылка: разрешённая тренировка отличается от запрещённого
«рерайта за студента». Не обходите гард-рейлы.

## Маркеры уверенности

Навыки-генераторы контента маркируют уверенность инлайн. Правило или
карточка без маркера — то, в чём навык уверен (но это всё равно не замена
вашей собственной сверке с источником перед экзаменом):

- `[ПРОВЕРЬ: утверждение — сверь с источником]` / `[VERIFY: …]` — скорее
  всего верно, но подтвердите по вашему конспекту, учебнику или первоисточнику
  (pravo.gov.ru, kad.arbitr.ru, КонсультантПлюс). Используется щедро.
- `[НЕУВЕРЕН: конкретная причина]` / `[UNCERTAIN: …]` — навык не уверен
  в этом конкретном суждении (спорный подход в практике, редакция нормы,
  редкий регион). Решайте сами; проверяйте источник.
- `[GAP — заполни из конспекта]` — маркер outline-builder для темы, где
  навыку не на что опереться и он не выдумывает норму.
- `[НУЖНЫ ДЕЛА — норма есть, но нет иллюстрирующего дела]`
- `[СВЕРЬ С КОНСПЕКТОМ ЛЕКЦИЙ — преподаватель мог акцентировать это]`
- `[ИСКЛЮЧЕНИЕ НЕЯСНО — в учебнике упомянуто исключение, найди норму]`
- `[НЕУВЕРЕН — рамка]` — маркер exam-forecast: прогноз — это весовой
  коэффициент для распределения времени, не предсказание.

Доверяйте флагам больше, чем их отсутствию: немаркированное правило — то,
в чём навык уверен, но перед экзаменом всё равно сверяйте с источником.

## Источники и проверка цитат

Без подключённого инструмента поиска каждая цитата норм/дела получает тег
`[проверь]`, а Reviewer note фиксирует, что источники не проверены.
Плагин работает в любом случае; с источником — просто делает больше
проверки за вас.

Тегирование источников: цитата, реально полученная из **kad.arbitr.ru**
(картотека арбитражных дел, практика АС/ВС), **pravo.gov.ru** (официальное
опубликование НПА) или **КонсультантПлюс/Гарант**, помечается её источником
и может быть отслежена. Цитата из памяти модели или из web_search — тег
`[проверь]` / `[проверь с точность до пункта]`, проверять по первоисточнику
(pravo.gov.ru — актуальная редакция; kad.arbitr.ru — живая практика), прежде
чем на неё опираться. Плагин тиражирует источники так, чтобы время проверки
шло туда, где это важно.

## Хранение

Профиль студента — `~/.hermes/legal/law-student/CLAUDE.md` — переживает
обновления плагина. Остальное — в рабочей директории:

```
law-student/
├── flashcards/
│   └── [предмет]/cards.md             # колоды по предметам
├── irac-sessions/
│   └── [студент]/
│       ├── [дата]-[тема].md           # разбор отдельной сессии
│       └── tracker.md                 # паттерны между сессиями
├── writing-feedback/
│   └── [студент]/
│       ├── [дата]-[работа].md         # разбор отдельной работы
│       └── tracker.md                 # паттерны между сессиями
└── exam-forecasts/
    └── [курс]/
        └── forecast-[YYYY-MM-DD].md   # версионированные прогнозы
```

## Как плагин учится

Профиль в `~/.hermes/legal/law-student/CLAUDE.md` не статичен — он улучшается
по мере использования. Навыки подсказывают, когда выход опирался на дефолт,
который стоит настроить. Можно перезапустить cold-start, править файл
напрямую или говорить навыку записать новую позицию.

## Заметки

- «Тренируй меня» vs «объясни мне» задаётся на cold-start; переключается
  покомандно.
- Конспекты и опорные конспекты — в ВАШЕМ формате. Если есть готовые
  конспекты, укажите их cold-start.
- Bar-prep целякт в слабые предметы из профиля. Не отстанет от них.
- Каждый навык-генератор помечает неуверенность. Доверяйте флагам больше,
  чем их отсутствию — но перед экзаменом проверяйте источником в любом случае.
