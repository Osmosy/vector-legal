# /flashcards

1. Загрузить `~/.hermes/legal/law-student/CLAUDE.md` → текущие курсы, слабые
   предметы, пути конспектов.
2. Применить фреймворк ниже.
3. Маршрут по флагу:
   - `--generate`: собрать карточки из источника (путь конспекта, заметки,
     учебник) по правилам письма карточек. Записать в
     `~/.hermes/legal/law-student/flashcards/[предмет]/cards.md`.
   - `--drill` (дефолт): приоритет — карточки к сроку + новые; показать
     вопрос, ждать ответ, показать ответ, взять самооценку, обновить ящики
     и следующий повтор.
   - `--review`: просмотр колоды по ящикам.
   - `--stats`: снимок прогресса; флаг залипших карточек для устного
     разбора.
   - `--сессия <n>`: сфокусированная сессия из N карточек, приоритет по
     прошлым промахам + карточкам к сроку; результаты — в `study-plan.yaml`
     → `session_history`.
4. Дисциплина уверенности: каждая карточка, сгенерированная из памяти без
   источника, получает `[ПРОВЕРЬ]`.

## Проверка реального дела

Если вопрос звучит как про РЕАЛЬНУЮ ситуацию — реальные суммы, договоры,
сроки — стоп.

> «Это похоже на реальную ситуацию, не учебный казус. Я не консультирую —
> и ты пока не юрист. Если реально — юристу: ФЗ-324, юрклиника вуза,
> адвокатская палата региона. Учить нормы — сколько угодно; решать дело —
> нет.»

Триггеры: реальные имена, адреса, даты, суммы, «мой работодатель/поставщик/
арендодатель», «пришла претензия/иск».

## Purpose

Опорные конспекты — для синтеза; карточки — для заучивания. Экзамены
(и тестовая часть письменного этапа экзамена на статус) награждают быстрое
воспроизведение нормы. Навык генерирует карточки из твоего конспекта (или
заметок, учебника), гоняет их с лёгким интервалированием и трекает, что
залипло.

**Не полноценная SRS-система.** Простые ящики Лейтнера. Достаточно для
учёбы, легко в поддержке. Хочешь Anki — Anki; это для случая, когда ты
в чате и хочешь быстрый тренаж.

## Дисциплина уверенности

То же правило, что у других навыков-генераторов:

- Карточки из источника, который дал студент (конспект, заметки, учебник) —
  вопрос и ответ из источника. Уверенно.
- Карточки из памяти модели без источника — на каждой карточке с нормой, в
  которой нет полной уверенности: `[ПРОВЕРЬ: норму — сверь с источником]`.
  Проверить до заучивания: карточка с ошибочной нормой, доведённая до
  мастерства, хуже отсутствия карточки.
- Не знаю область — сгенерирую меньше, а не выдумывать. Лучше 8 хороших
  карточек, чем 20, из которых 5 неверных. Ссылки и реквизиты — `[проверь]`.

## Режимы

Флаг: `--generate | --drill | --review | --stats | --сессия <n>` (дефолт:
спросить)

### `--сессия <n>` — сфокусированная сессия из N карточек

Для «давай 5 карточек по договорам» или
`/law-student:session Гражданское право 5 --flashcards`.

- Загрузить `study-plan.yaml` и читать `session_history` по предмету.
- Приоритет: карточки, отмеченные неверно ранее > к сроку > новые.
- Прогнать N карточек по одной в потоке `--drill`.
- В конце добавить результаты в `study-plan.yaml` → `session_history`:

```yaml
session_history:
  - date: 2026-05-08
    subject: Гражданское право
    type: flashcards
    n_cards: 5
    right: 3
    partial: 1
    wrong: 1
    stuck_topics: [parol-evidence-rule]
```

- Нет `study-plan.yaml` — писать в
  `~/.hermes/legal/law-student/session-history.yaml`.

### `--generate` — создать карточки

**Входы:**
- Предмет (курс или тема)
- Источник (путь конспекта, заметки или «возьми мой конспект из профиля»)
- Опционально: целевое число карточек (дефолт 10–20 за сессию)

**Структура карточки:**

```markdown
### Карточка [N]
**В:** [вопрос — один концепт, одна карточка]
**О:** [ответ — норма, одно–два предложения]
**Источник:** [раздел конспекта, страница учебника, дата лекции]
**Ящик:** new
**Последний повтор:** —
**Следующий повтор:** [сегодняшняя дата]
**Заметки:** [опционально — различия, исключения, ловушки]
```

**Правила письма карточек:**
1. **Один концепт на карточку.** «Элементы состава» — это 4 карточки, не 1.
2. **Лицо — вопрос, не тема.** «Меры ответственности» — плохо. «Какие
   четыре элемента состава правонарушения?» — хорошо.
3. **Оборот — норма, не абзац.** Ответ шире абзаца — разбить на карточки.
4. **Указать источник**, чтобы сверяться во время тренажа.

**Проверка цитат.** Карточки из памяти модели, а не из вставленного
источника: норма и реквизиты на обороте сгенерированы ИИ и не
верифицированы. Прежде чем заучивать карточку — сверить с конспектом,
учебником или источником (pravo.gov.ru, КонсультантПлюс, kad.arbitr.ru).
Неверная карточка, доведённая до мастерства, хуже отсутствия карточки.

### `--drill` — учебная сессия

**Приоритизация:**
1. Карточки, где `next_review <= сегодня` И ящик != mastered
2. Новые карточки, ещё не тронутые
3. Нет ни к сроку, ни новых: спросить, не желает ли студент повторение
   mastered-карточек (профилактика выцветания)

**Поток по каждой карточке:**
1. Показать вопрос. Ждать ответа.
2. Студент отвечает (или пишет «skip» / «не знаю»)
3. Показать ответ.
4. Самооценка: `верно` / `частично` / `неверно` / `не знаю`
5. Обновить ящик + следующий повтор по таблице:

| Самооценка | Изменение ящика | Следующий повтор |
|---|---|---|
| верно | вверх на один (new → learning → review → mastered) | +1д new, +3д learning, +7д review, +21д mastered |
| частично | тот же ящик | +1д |
| неверно | вниз на один (review → learning; learning → new; new остаётся new) | сегодня +4ч |
| не знаю | вниз на один | сегодня +4ч |

### `--review` — просмотр колоды

Показать все карточки предмета. Сгруппированы по ящикам. Удобно для
сканирования состава колоды и ручной правки содержания.

### `--stats` — снимок прогресса

По предмету: всего карточек, распределение по ящикам, к сроку сегодня,
просмотрено на этой неделе. Подсветить карточки, откатывавшиеся в `new`
больше двух раз — это залипшие концепты, которые стоит разобрать устно
через `/law-student:socratic-drill`.

## Интеграция с другими навыками

- **outline-builder:** после постройки/расширения конспекта предложить
  сгенерировать карточки из нового материала
- **socratic-drill:** карточка промахивалась 2+ раза — путь в
  `/law-student:socratic-drill` для устного разбора: карточки не заменяют
  понимание того, что не понимаешь
- **bar-prep-questions:** предметы с плохой карточной статистикой получают
  больший вес в тестовом тренаже

## Хранение

```
flashcards/
└── [предмет]/
    └── cards.md
```

Один файл на предмет. Карточки в markdown. Метаданные ящика и повторов —
инлайн в карточке. Не оптимум для очень больших колод (>500), но для типовых
студенческих — норм.

## Чего этот навык не делает

- **Не заменить Anki.** Привычка к Anki есть — веди её. Это для тренажа
  в чате без переключения приложений.
- **Не добивать до целевого числа.** Из источника выходит 8 уверенных
  карточек — получишь 8. Разбавление `[ПРОВЕРЬ]`-догадками хуже меньшей
  колоды.
- **Не требует дисциплину.** Пропущенные дни повторов накапливаются;
  навык только показывает, что к сроку. Гонять или нет — решаешь ты.
- **Не учит норме.** Карточки — тренаж изученного. Карточка стабильно
  неверно отвечается — проблема выше по течению: `/law-student:socratic-drill`
  или перечитать источник.
- **Не гарантирует актуальность норм.** Редакции меняются; карточка со
  «старой» нормой — реальная ловушка; при `--stats` по старым колодам
  предлагать ревизию норм по источнику.
