## Готово

### ✅ commercial-legal — 15 навыков (пилот, готов 28.08.2026)

`commercial-legal/` — первый полностью адаптированный домен. Скелет CFL
(практика-профиль + cold-start interview + routing) + российское право.

| Навык | Что делает (RU-специфика) |
|---|---|
| cold-start-interview | Интервью → practice profile (playbook двух сторон, эскалации, house style, seed-договоры) |
| customize | Точечная правка профиля без переинтервью |
| matter-workspace | Пространства дел для firm-практик (in-house — выключено) |
| review | Маршрутизатор: тип договора по заголовкам → профильный навык |
| vendor-agreement-review | MSA/поставка/услуги/подряд — 4-мерный лимит ответственности, императивы ГК (п. 4 ст. 401 — ничтожность ограничения за умысел, ст. 333 — снижение неустойки), претензионный порядок АПК, протокол разногласий |
| nda-review | GREEN/YELLOW/RED триаж; ФЗ-98 (режим КТ фактически), ст. 330 (неустойка), ст. 13.11 КоАП (оборотные штрафы за утечку) |
| saas-msa-review | SaaS-слой поверх vendor-review: автопродление (ст. 425), повышение цен, SLA+credits, 152-ФЗ у вендора (поручение, локализация ч.5 ст.18, ТИПЗ ФСТЭК №21, трансграничка ст.12+приказ РКН №931), exit/миграция |
| amendment-history | Трейс цепочки допсоглашений (ст. 450, 452) до текущей контролирующей редакции |
| renewal-tracker | Реестр продлений с send_by/cancel_by (business-day roll-back по производственному календарю РФ), полосы срочности |
| escalation-flagger | Эскалации по матрице, драфт запроса |
| review-proposals | Очередь предложений playbook от монитор-агента; юрист решает |
| stakeholder-summary | Двухминутный ответ бизнесу «подписывать или нет» |
| vector-check | Due diligence контрагента (EGRUL, ФССП, kad.arbitr, Федресурс, 115-ФЗ, санкции) — перенесён из старого drafts/ |

**Practice profile** (`commercial-legal/CLAUDE.md`): playbook по сторонам
(продажи/закупки), 152-ФЗ, «одна вещь»-deal-breaker, матрица эскалаций,
house style, RU-headers (адвокатская тайна ст.8 ФЗ-63 vs КТ ФЗ-98 vs
внутренний анализ), теги источников (`[kad.arbitr.ru]`, `[pravo.gov.ru]`,
`[КонсультантПлюс]`), currency-trigger, no-silent-supplement, destination check.

## Принцип адаптации

1. **Скелет CFL переносится** (practice profile, cold-start, маршрутизация,
   guardrails, reviewer note, decision tree, provenance-теги — это лучшая
   практика формы).
2. **Содержание — только из источников права РФ.** Никаких «рыночных
   дефолтов» из US-версии: ст. 15/330/401/425 ГК, 152-ФЗ, ТК, АПК, КоАП —
   каждый раздел ссылается на норму, а каждый playbook — только на seed-
   договоры команды.
3. **Коннекторы РФ:** kad.arbitr.ru, pravo.gov.ru, ЕГРЮЛ, Федресурс, ФССП —
   через web_search + тег `[verify]`, пока нет своих MCP; ЭДО/Диадок/СБИС —
   плейсхолдеры с ⚪.
4. **Не является юридической позицией** Osmosy или Anthropic — инструменты
   для юристов, дисклеймер в каждом плагине.
