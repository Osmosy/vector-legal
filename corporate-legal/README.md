# Corporate Counsel — Корпоративное право и M&A (Vector Legal)

Адаптация [claude-for-legal/corporate-legal](https://github.com/anthropics/claude-for-legal)
(Anthropic, Apache-2.0) под российское право и Hermes Agent.

## Что это

In-house корпоративный юрист в праве РФ: M&A (покупка/продажа долей и бизнеса,
ООО и АО), корпоративный секретариат (решения ОСУ/СД, протоколы), корпоративный
комплаенс по юрлицам (ФНС, ЕГРЮЛ, лицензии) и пост-закрытие.

Выход — черновик для проверки юристом: `read the documents` → применить
playbook → найти вопросы → собрать memo. Юрист проверяет, верифицирует и решает.

## ⚠️ Юридический дисклеймер (канонический)

**Всё, что производит плагин, — черновик для проверки юристом.** Не юридическая
консультация, не правовое заключение, не замена юриста. Каждый документ
требует проверки квалифицированным специалистом. Источники указываются явно.
Теги источников описывают происхождение цитаты, не её правильность.

## Быстрый старт

```
cold-start-interview              # модульное интервью → practice profile
tabular-review --template ma-diligence-rf --docs ./dataroom/
```

До cold-start все навыки работают в **provisional mode** (см. README
commercial-legal — тот же принцип): generic дефолты права РФ с меткой
`[PROVISIONAL]`.

## Practice profile

Конфигурация: `~/.hermes/legal/corporate-legal/CLAUDE.md`. Шаблон — `CLAUDE.md`
в корне плагина. Содержит:

- **Роль пользователя** (юрист / не-юрист с юристом / не-юрист) — определяет
  header выходных документов и consequential-action gates
- **Тип юрлица и применимый закон** (ООО — 14-ФЗ, АО — 208-ФЗ, ИП —
  особенности; для каждого — своя матрица корпоративных полномочий)
- **Матрица корпоративных полномочий**: кто из ген. директора / совета
  директоров / общего собрания что одобряет. Центральные нормы:
  - крупные сделки: ст. 46 ФЗ-14 (ООО), ст. 46–47 ФЗ-208 (АО, в ред.
    249-ФЗ от 01.01.2017 — единый термин «крупная сделка»; критерий 25%
    балансовой стоимости активов)
  - сделки с заинтересованностью: ст. 45 ФЗ-14 (ООО) / ст. 84 ФЗ-208 (АО);
    для ООО — одобрение не требуется, если доли голосующих ≤ 0,01% +
    неконфликтные органы (п. 7 ст. 45 ФЗ-14)
  - крупные сделки: одобрение общим собранием, а для АО — советом директоров
    при стоимости 25–50% единогласно, свыше 50% — квалифицированным
  - уставные ограничения сделки (ст. 173.1 ГК — оспоримые сделки без
    необходимого в силу закона одобрения)
- **Эскалации** с именами/ролями и каналами
- **House style** — формат протокола/решения, язык резолюций, seed-документы

### Право Российской Федерации (базовые замены против US-версии)

| CFL (US) | Vector Legal (RU) |
|---|---|
| Unanimous written consent (board) | Единогласное письменное решение: ООО — ст. 38 ФЗ-14 (только единогласное; для АО не предусмотрено — решения СД принимаются на заседании, но допускается опрос/заочное голосование ст. 50 ФЗ-208 и внутренними документами, если не запрещено уставом (ст. 47 п. 1 абз. 2 ФЗ-208) `[запутанная норма — verify]`) |
| DGCL 141(f) / notice-to-nonsigning | Письменное решение ООС ООО — единогласие всех участников (ст. 38 ФЗ-14); протокол — ст. 181.2 ГК (форма протокола решения, перечень обязательных сведений) |
| Board minutes | Протокол ОСУ: ст. 37 ФЗ-14 (ООО: кворум, нотариальное удостоверение протокола — по умолчанию, если устав/единогласие всех участников не предусматривают иное — пп. 11 п. 1 ст. 50.1 ФЗ-14, ст. 67.1 ГК); протокол СД АО — ст. 68 ФЗ-208 |
| DE franchise tax / annual report | Подтверждение осн. вида деятельности в ФНС до 30 апреля (ст. 5, 7 ФЗ-348, классификация по ОКВЭД2 с наибольшей долей за отчётный год); ежегодная бухгалтерская отчётность в ФНС/Госкомстат до 31 марта (ФЗ-402, приказ ФНС ММВ-7-3/858@); ЕГРЮЛ-актуальность (директор, адрес, устав) |
| Secretary of State good standing | Актуальная выписка ЕГРЮЛ (egrul.nalog.ru/nalog.ru — `egrul.nalog.ru`), отсутствие записи о недостоверности сведений (п. 6 ст. 14.25 КоАП-риски, ст. 21.1 ФЗ-129 — исключение недействующего юрлица), актуализация устава в ФНС |
| HSR / merger control | ФАС: предварительное согласование ст. 28/29/32 ФЗ-135 (ходатайство), пост-сделочное уведомление; пороги по активам/выручке — обновляются постановлением Правительства, уточнять ежегодно `[verify — порог меняется]` |
| CFIUS / foreign investment | Постановление Правительства № 618 (установление иностранных инвесторов), ФЗ-57 ограничения для 36+ стратегических ВИДов; проверка «происхождения» — ст. 3 ФЗ-160 |
| Sector regulators | ЦБ РФ — для финансовых организаций (Положения ЦБ на сделки с ЦК по ст. 84 ФЗ-208/ст. 45 ФЗ-14 + ст. 20.1 ФЗ-208 — согласование ЦБ для публичных АО); Минфин отраслевые лицензии (медицина, фарма, алкоголь) |
| Delaware MAC / MAE in SPA | SPA по российскому праву: заверения об обстоятельствах (ст. 431.2 ГК) и возмещение потерь (ст. 406.1 ГК); MAC-оговорка используется реже — проверка на «существенность» и императивные нормы |
| Stock purchase agreement | Договор об отчуждении долей/ценных бумаг: доли ООО — обязательно нотариальное удостоверение (ст. 21 ФЗ-14, ст. 42.1 основ законодательства о нотариате), переход доли — с момента внесения в ЕГРЮЛ (ст. 21.4); акции — реестр АО, передаточное распоряжение регистратору; доли — уведомление общества ст. 21.4 ФЗ-14 |
| Disclosure schedule | Раскрытие/уточнение заверений: перечень существенных договоров с существенными условиями (см. material-contract-schedule) — в договоре о продаже долей это приложение к заверениям, а не отдельный раздел SPA `Schedule 3.X` |
| Stockholder approval thresholds | ОСУ: крупные сделки/заинтересованность — ст. 46 ФЗ-14 / ст. 79, 84 ФЗ-208; для АО — «крупная» + «заинтересованность» + «реорганизация/ликвидация» — квалифицированное 3/4 голосов (ст. 49 п. 4 ФЗ-208) |
| Attorney work product | Адвокатская тайна (ст. 8 ФЗ-63) — только для адвоката. Иначе: `КОНФИДЕНЦИАЛЬНО — ВНУТРЕННИЙ ПРАВОВОЙ АНАЛИЗ`. Режим коммерческой тайны ФЗ-98 — фактическая защита |

Это замены каркаса; конкретные позиции матрицы полномочий — только из
интервью и уставов юрлиц группы (никаких дефолтов «с потолка»).

## Provisional mode

До заполнения профиля: generic дефолты (РФ, ООО как самый частый тип, средняя
крупность сделок, заголовки решения/протокола из первых принципов —
ст. 181.2 ГК, ст. 37 ФЗ-14). Каждый выход помечается
`[PROVISIONAL — запусти cold-start-interview для калибровки]`.

## Отличия от CFL

1. Право РФ вместо US: 14-ФЗ (ООО) / 208-ФЗ (АО) / ГК РФ вместо DGCL/MBCA,
   ФАС вместо HSR, ЦБ/ЦК-регуляторика для финансовых юрлиц, ЕГРЮЛ вместо
   Secretary of State
2. Пути: `~/.hermes/legal/corporate-legal/` вместо
   `~/.claude/plugins/config/claude-for-legal/corporate-legal/`
3. Интеграции: Ironclad/DocuSign/iManage → КонсультантПлюс/Гарант
   (web_search, официального MCP нет), Диадок/СБИС (ЭДО), КриптоПро УКЭП;
   VDR — Box/Диск/папка
4. CourtListener → kad.arbitr.ru + ras.arbitr.ru (практика), e-justice —
   для проверки судимостей директоров `[нет API — web_search + verify]`
5. Slack → Telegram через Hermes gateway
6. Публичные АО: не дублируем SEC-модуль (upstream «Public Company»),
   в РФ — акционерные соглашения (ст. 32.1 ФЗ-208), раскрытие ЦК
   (ФЗ-39, ЛПР/КСП), решения ЦБ; отдельного модуля в этой версии нет
   — секция профиля под публичные АО сохранена как scaffold, навыки не
   входят (`[roadmap]`)

## Интеграции (как в CFL — фоллбэки встроены)

- **VDR / dataroom** — Box/Диск/Nextcloud/локальная папка. Без MCP — dataroom
  подтягивается путём к папке
- **ЭДО (Диадок/СБИС)** — опционально; подписание вне плагина
- **ПК «КонсультантПлюс» / Гарант** — нет MCP; web_search + `[verify]`
- **ЕГРЮЛ/ЕГРИП** — `egrul.nalog.ru`, без API; пользователь скачивает выписку
 или вводит ИНН, навык проверяет вручную введённые данные
