# /customize — правка practice profile AI Governance

## Когда запускается

Пользователь хочет изменить что-то в practice profile — red line,
порог governance tier, регуляторный профиль, интеграции — без перезапуска
cold-start интервью.

## Что делать

1. **Прочитать конфиг** `~/.hermes/legal/ai-governance-legal/CLAUDE.md`
   (и `~/.hermes/legal/company-profile.md` уровнем выше). Плейсхолдеры →

   > Setup не запускался. Сначала `cold-start-interview` — customize
   > правит уже существующий профиль.

2. **Показать карту правок** — секции с текущим значением одной строкой:

   - **Компания** — AI-activity summary, регуляторный профиль (ЭПР ИИ,
     ГОСТ-требования, экспорт), отрасль *(company-profile.md — общий)*
   - **Роль и контакт юриста** — влияет на header выходных документов
   - **Use case registry** — одобренные use-case'ы, условия, причины
   - **Red lines** — автоматические «нет» и их основания
   - **Governance tiers** — пути одобрения по уровням риска
   - **Реестр ИИ-систем** — путь к ai-systems.yaml, cadence review
   - **152-ФЗ блок** — практические правила ПДн в ИИ-системах
   - **House style assessing'а** — формат AIA, язык, хранение
   - **Интеграции** — хранилище, cron, Telegram, базы
   - **Matter workspaces** — пути, cross-matter

3. **Процитировать текущее значение** выбранной секции.

4. **Спросить новое значение.** Одно поле за раз.

5. **Показать diff** (старое → новое) **и ждать подтверждения.**

6. **Записать** в practice profile.

7. **Показать подтверждение** + «Изменение затронет: [какие навыки/выходы]».

## Конвенции

- **Одно поле за одну правку** — «измени red line» и «обнови tiers» —
  два вызова
- **Цитировать перед изменением**
- **Подтверждать перед записью** — diff, ждать yes
- **Обновить verification log** при изменении факта: `[дата] [поле:
  старое → новое] изменено [кем]`
- **Не изменять seed documents** таблицу — только через `--redo`

## Типовые правки

- «Добавь red line: обучение моделей на данных клиентов» → уточнить
  формулировку (все модели / свои / вендорские), записать, показать,
  какие реестровые записи это затронет
- «Уровень „Высокий“ теперь проходит через CTO» → обновить governance
  tiers + отметить, активные AIA не трогаются
- «Политики хранятся в Nextcloud /legal/ai-policy» → обновить house style
  и сказать, что `policy-monitor` теперь будет читать оттуда
- «Мы экспортируем: добавь EU-модуль» → предложить обновить реестр систем
  (eu_nexus) и предложить `ai-inventory classify` для затронутых систем
- «Мы вошли в ЭПР ИИ» → обновить регуляторный профиль с пометкой
  `[verify]` (проверить реестр ЭПР web_search'ом и записать дату
  проверки) + предложить `reg-gap-analysis` по обязательствам ЭПР
