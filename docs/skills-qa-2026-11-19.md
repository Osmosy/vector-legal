# Skills QA: `norm-validity-check` и `document-anonymize`

Прогон по методике `legal-builder-hub/skills/skills-qa` (тринадцать параметров
дизайна, скан prompt-injection, карта зависимостей, три юридических failure
mode). Выполнен 19.11.2026 агентом на собственных навыках репозитория — до
развёртывания в команду, как предписывает навык.

## Скан prompt-injection (эвристический, не аудит безопасности)

Проверены оба `SKILL.md` по десяти категориям (override-инструкции, заявления
полномочий, изменение конфигов, чтение/запись вне области, внешние URL,
скрытый контент, shell-исполнение, запросы кредов, юридическое overclaiming).

**Находок нет.** Внешний URL один — `http://pravo.gov.ru` в справочном блоке о
доступности источников, по назначению навыка. Shell-команд, вызовов
`skill_manage` на чужие навыки, cron-триггеров, запросов ключей нет. Оба навыка
работают только через `web_search` / `web_extract`.
