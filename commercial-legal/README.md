# Commercial Counsel — Коммерческие договоры (Vector Legal)

Адаптация [claude-for-legal/commercial-legal](https://github.com/anthropics/claude-for-legal)
(Anthropic, Apache-2.0) под российское право и Hermes Agent.

## Что это

In-house ревизия коммерческих договоров: входящий договор разбирается против
**playbook твоей команды** (не «рыночного стандарта»), каждое отклонение
получает severity, объяснение бизнес-эффекта, конкретную редакцию правки
(не «рассмотреть возможность изменения») и решение по эскалации.

Выход — memo, которое юрист проходит за один проход.

## ⚠️ Юридический дисклеймер (канонический)

**Всё, что производит плагин, — черновик для проверки юристом.** Не юридическая
консультация, не правовое заключение, не замена юриста. Каждый документ
требует проверки квалифицированным специалистом. Источники указываются явно.

## Структура

```
commercial-legal/
├── CLAUDE.md                      # Шаблон practice profile (заполняет cold-start)
├── README.md                      # Этот файл
└── skills/
    ├── cold-start-interview/      # Интервью → пишет practice profile
    ├── customize/                 # Точечная правка профиля
    ├── matter-workspace/          # Рабочие пространства дел (для firm/мультиклиент)
    ├── review/                    # Маршрутизатор: какой тип договора → какой скилл
    ├── vendor-agreement-review/   # Ревизия MSA/договоров поставки/услуг
    ├── nda-review/                # GREEN/YELLOW/RED триаж NDA
    ├── saas-msa-review/           # Ревизия SaaS-подписок (автопродления, SLA)
    ├── amendment-history/         # Трекинг допсоглашений
    ├── renewal-tracker/           # Реестр продлений
    ├── escalation-flagger/        # Эскалации по матрице
    ├── review-proposals/          # Очередь предложений к playbook
    └── stakeholder-summary/       # Саммари для бизнеса
```

## Быстрый старт

```
cold-start-interview          # 2 мин quick / 10 мин full — пишет practice profile
review <договор>              # Маршрутизация и ревизия
```

До cold-start все навыки работают в **provisional mode**: generic дефолты
(российское право, средний риск-аппетит) с меткой `[PROVISIONAL]` — см. ниже.

## Practice profile

Конфигурация живёт в `~/.hermes/legal/commercial-legal/CLAUDE.md` (в
Claude-версии — `~/.claude/plugins/config/...`; здесь путь Hermes-нативный).
Шаблон: `CLAUDE.md` в корне плагина. Профиль содержит:

- **Роль пользователя** (юрист / не-юрист с доступом к юристу / не-юрист) —
  определяет header выходных документов
- **Playbook по сторонам** (продажи/закупки отдельно): limitation of liability
  (4 позиции, не одна), indemnity, 152-ФЗ/data protection, срок и расторжение,
  применимое право и суд (арбитраж/третейская оговорка), **«одна вещь»** —
  deal-breaker, который проверяется первым
- **Матрица эскалаций** с порогами и автоматическими эскалациями
- **House style**, интеграции, seed-договоры (позиции playbook извлекаются
  из реально подписанных договоров)

### Право Российской Федерации (базовые замены против US-версии)

| CFL (US) | Vector Legal (RU) |
|---|---|
| Attorney work product (FRCP 26(b)(3)) | Адвокатская тайна (ст. 8 ФЗ-63 «Об адвокатуре»); для не-адвокатов — коммерческая тайна (ФЗ-98). Header для юриста: `КОНФИДЕНЦИАЛЬНО — АДВОКАТСКАЯ ТАЙНА` (только если готовит адвокат); иначе `КОНФИДЕНЦИАЛЬНО — ВНУТРЕННИЙ ПРАВОВОЙ АНАЛИЗ — НЕ ЗАМЕНЯЕТ КОНСУЛЬТАЦИЮ ЮРИСТА` |
| Delaware/NY governing law | РФ: право РФ, АС города/региона компании; экспортные сделки — рассмотреть ESF/LCIA, но помнить про §248 АПК и императивные нормы |
| State courts / arbitration | АС (арбитражные суды) по умолчанию; третейская оговорка — проверка на «третейскую оговорку, неподконтрольную стороне» (ст. 14 ФЗ-382) и компетенцию МКАС |
| GDPR DPA | 152-ФЗ: согласие субъекта, локализация ПДн (ч. 5 ст. 18), приказ №179/уполномоченный, модельные условия приказов Роскомнадзора; трансграничная передача — уведомление РКН (ст. 12), перечень стран из приказа №931 |
| Uncapped liability | Ст. 15, 400 ГК: неустойка/убытки; проверка на ст. 401.1 (предпринимательская ответственность без вины), запрет ограничивать ответственность за умышленное нарушение (п. 4 ст. 401 ГК — императив, условие ничтожно) |
| Non-compete (ат-вилл) | Ст. 27 Конвенции + ТК РФ: неконкуренция сотрудников почти неприменима; для контрагентов — ст. 10 ГК (злоупотребление), антимонопольные риски (ФЗ-135) |
| Auto-renewal | Ст. 425, 426 ГК + практика ФАС; автопродление в публичных договорах — проверка на навязывание |
| SLA / penalties | Неустойка по ст. 330 ГК; проверка на снижение по ст. 333 (суд снижает несоразмерную) — для нас это и риск, и защита |
| e-signature (ESIGN/UETA) | ФЗ-63 «Об электронной подписи»: УКЭП/ПЭП, ст. 6 (равнозначность), для договоров с гос-вом — ГИС ЭП |

Это замены каркаса; конкретные позиции playbook — только из интервью и
seed-договоров команды (как в CFL: никаких дефолтов «с потолка»).

## Provisional mode

До заполнения профиля все ревизии работают с generic дефолтами: право РФ,
средний риск-аппетит, позиции из первых принципов (ст. 15, 330, 401 ГК —
расчёт убытков и неустойки; неограниченная ответственность за умысел;
отсутствие DPA 152-ФЗ; автопродление без окна отмены). Каждый выход
помечается `[PROVISIONAL — запусти cold-start-interview для калибровки]`.

## Отличия от CFL

1. Право РФ вместо US (таблица выше), юрисдикция в профиле — обязательное поле
2. Пути: `~/.hermes/legal/` вместо `~/.claude/plugins/config/`
3. Интеграции: Ironclad/DocuSign/iManage/Everlaw → КонсультантПлюс/Гарант
   (через web_search, т.к. официального MCP нет), Диадок/СБИС (ЭДО), Контур.
   Элема — заглушки в профиле с пометкой ⚪
4. CourtListener → **kad.arbitr.ru** (картотека арбитражных дел) + sudrf.ru;
   готового MCP нет — скилл использует web_search + пометку `[verify]`
5. Slack-уведомления → Telegram через Hermes gateway
