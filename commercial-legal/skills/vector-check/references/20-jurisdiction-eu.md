# Юрисдикция — EU

Проход по европейским целям: национальные реестры, регуляторные рамки,
экспортный контроль. **Ключевая особенность:** единого реестра юрлиц в ЕС нет —
регистрация в каждой стране своя, поэтому проверка идёт по стране инкорпорации,
а не «по ЕС».

## Реестры по странам

| Страна | Реестр | Что даёт |
|--------|--------|----------|
| DE | Unternehmensregister / Handelsregister | устав, управление, отчётность |
| FR | Infogreffe / Annuaire des entreprises | регистрация, финансы, руководители |
| NL | KVK | регистрация, UBO-реестр |
| IT | Registro Imprese | регистрация, отчётность |
| ES | Registro Mercantil | регистрация, отчётность |
| PL | KRS (Krajowy Rejestr Sądowy) | регистрация, отчётность, управление |
| CZ | Justice.cz | регистрация, финансы |
| SE | Bolagsverket | регистрация, отчётность |
| IE | CRO | регистрация, отчётность |

**Сводные точки входа:** BRIS (Business Registers Interconnection System, e-Justice) —
доступ к связанным реестрам ЕС; OpenCorporates — агрегатор без гарантии полноты.

## Обязательные проверки

### Реестр конечных владельцев (UBO)
Директива AML (AMLD) обязывает страны вести реестры бенефициаров. Практика
доступа у стран разная: часть открыта (DE частично, NL частично), часть требует
«законного интереса».

- Проверить, кто заявлен UBO и совпадает ли с фактическим владением
- Отсутствие данных UBO — не «чисто», а пробел: запрашивать раскрытие напрямую

### Санкции и экспортный контроль
- **EU Consolidated List** (Reg. 269/2014 и иные) — см. `07-sanctions.md`
- **Приложение IV Reg. 833/2014** — усиленные ограничения для РФ и посредников
- **Dual-use (Reg. 2021/821)** — товары двойного назначения
- **Антиобходные меры**: сделки с третьими странами (Турция, ОАЭ, Казахстан, КНР,
  Узбекистан) требуют усиленной проверки конечного получателя

### Регуляторика по профилю
| Профиль | Что смотреть |
|---|---|
| Финансы | национальный регулятор (BaFin, ACPR, DNB), лицензии, MiFID/MiCA |
| Данные | GDPR (см. ниже), национальные DPA |
| Продукты | CE-маркировка, директива о безопасности продукции |
| Рынки | реестры участников (ESMA, национальные) |

## Данные и GDPR

| Что проверять | Норма | Практика |
|---|---|---|
| Правовое основание обработки | ст. 6 GDPR | нет основания — необратимый риск |
| Передача за пределы ЕС | гл. V GDPR | SCC, adequacy decision; передача в РФ — практически закрыта |
| Реестр обработки (Records of processing) | ст. 30 | наличие у контрагента |
| DPO | ст. 37 | обязателен для части операторов |
| Уведомление о нарушении | ст. 33 (72 ч) | срок в договоре |
| Штрафы | ст. 83 | до 4% мирового оборота или 20 млн € |

**Практическое следствие:** если российская компания — обработчик данных
EU-клиента, передача в РФ требует отдельного механизма; без него сотрудничество
юридически не выстраивается.

## ESG-обязанности ЕС (для цепочек поставок)

| Акт | Кого касается | Что значит для контрагента |
|---|---|---|
| **CSRD** | отчётность крупных компаний по устойчивости | EU-заказчик запрашивает данные по цепочке |
| **CSDDD** | due diligence по правам человека и экологии | неготовность контрагента = риск разрыва |
| **CBAM** | углеродоёмкие товары на ввозе | углеродный сбор, отчётность по выбросам |
| **EUDR** | товары, связанные с обезлесением | подтверждение происхождения |
| **ESPR** | экодизайн, цифровой паспорт продукта | требования к продукту после 2027 |

## Формат раздела отчёта

```markdown
## Юрисдикция: EU

- **Страна инкорпорации:** [DE/FR/NL/...]
- **Реестр:** [название], выписка от [дата]
- **UBO:** [раскрыт / нет; кто заявлен]
- **Санкции ЕС:** [совпадений нет / найдено]
- **Экспортный контроль:** [применимость dual-use, Annex IV]
- **GDPR:** [обработчик / контролёр; основание; передача за пределы ЕС]
- **ESG-контур:** [CSRD/CSDDD/CBAM применимость]
- **Красные флаги:** [...]
```

## Красные флаги

### Critical
- **Прямое попадание в EU Consolidated List** — сделка блокируется независимо
  от юрисдикции вашей компании
- **Обработка данных EU-субъектов без основания** — необратимое нарушение GDPR
- **Передача в РФ без механизма** — практически закрытый путь

### High
- **UBO не раскрыт** при требовании реестра
- **Приложение IV Reg. 833/2014** — сделка требует разрешения
- **CSDDD-неготовность** при значимой доле EU-выручки
- **Dual-use без лицензии** при поставке

### Medium
- **Отсутствие Records of processing** у обработчика данных
- **DPO не назначен** там, где обязателен
- **CBAM-товары** без учёта углеродного сбора

### Low
- **Устаревшая публичная отчётность** в национальном реестре

## Частые ошибки

1. **Искать «реестр ЕС»** — его нет; проверять по стране инкорпорации.
2. **Считать BRIS полным** — он покрывает не все страны и не все данные.
3. **Игнорировать UBO** — реестр бенефициаров есть почти везде, пробел в доступе
   не означает отсутствия требования.
4. **Смешивать GDPR и 152-ФЗ** — разные режимы; российский контрагент не может
   «применить 152-ФЗ» к субъектам ЕС.
5. **Не учитывать антиобходные меры** — сделки через третьи страны проверяются
   усиленно (см. `07-sanctions.md`).
