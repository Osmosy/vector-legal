# Домен 06 — ESG

В российской практике ESG почти никогда не решает сделку сам, но даёт два
практических результата: **репутационные и регуляторные риски** (особенно если
у компании есть европейские контрагенты или экспорт) и **скрытые обязательства**
(экологические платежи, нарушения, суды с надзорами).

**Оговорка, обязательная в отчёте:** рейтинги (MSCI, Sustainalytics, CDP)
покрывают крупные публичные компании. Для среднего российского бизнеса их нет —
домен собирается по открытым данным, и это указывается явно, без имитации оценки.

## Источники

| Источник | Что даёт | Когда |
|----------|----------|-------|
| Реестр Росприроднадзора | категория объекта НВОС, декларации, платежи | если есть производство |
| Федресурс / ЕГРЮЛ | экологические обязательства, обеспечение | Standard |
| kad.arbitr (фильтр по надзорам) | споры с Росприроднадзором, Ростехнадзором, ГИТ | Standard |
| Реестр проверок (proverki.gov.ru) | плановые и внеплановые проверки, результаты | Standard |
| FSC / ISO 14001 / ISO 45001 | подтверждённые системы управления | если заявлены |
| MSCI / Sustainalytics / CDP | рейтинги публичных компаний | Full, только крупные |

## Что извлекать и как форматировать

### Раздел отчёта «ESG»

```markdown
## 6. ESG

> Рейтингов ESG у компании нет (не публичная) — домен собран по открытым
> реестрам, оценка не присваивалась.

### Экология (E)
- **Объект НВОС:** [категория I–IV / не состоит на учёте]
- **Разрешительные документы:** [комплексное экологическое разрешение, декларация]
- **Плата за НВОС:** [есть задолженность / нет] `[verify]`
- **Споры с надзорами:** [N дел, суммы, исход]

### Социальное (S)
- **Проверки ГИТ:** [N, результаты — предписания/штрафы]
- **Травматизм, несчастные случаи:** [публичные сведения]
- **Судебные споры с работниками:** [N дел]

### Управление (G)
- **Структура управления:** [совет директоров, независимые]
- **Концентрация:** [доля контролирующего лица]
- **Связанные сделки:** [наличие с заинтересованностью — см. `02`]

### Экспортный контур (если есть)
- **CSRD/CSDDD применимость:** [попадает ли в цепочку поставок EU-заказчика]
- **CBAM:** [для товаров из перечня — углеродоёмкие]
- **Регламент ЕС по борьбе с обезлесением (EUDR):** [применимость]

### Красные флаги
- ⚠️ Незакрытая задолженность по плате за НВОС
- ⚠️ Предписания надзоров без устранения
- ⚠️ Входит в цепочку поставок EU-компании без CSDDD-готовности
```

## Красные флаги (ESG)

### Critical
- **Действующие предписания надзоров с угрозой приостановки деятельности**
- **Уголовные дела по экологическим составам** против руководителя

### High
- **Задолженность по плате за НВОС** сопоставимая с прибылью
- **Повторные нарушения, выявленные ГИТ** (системность, не случайность)
- **Экспорт в ЕС при товарах из CBAM-перечня** (углеродный сбор не учтён)
- **CSDDD-риск:** EU-заказчик обязан проверять цепочку — неготовность компании
  означает риск разрыва контрактов у контрагента, а не у нас напрямую

### Medium
- **Рейтинги ESG отсутствуют** при заявленной публичной ESG-политике на сайте
- **Нет ISO 14001/45001** при заявленных системах управления
- **Одиночные предписания** без повторных

### Low
- **Отсутствие публичной ESG-отчётности** для частной компании
- **Устаревшая информация** на сайте в разделе устойчивого развития

## Практическая ценность домена

Для российской сделки ESG чаще всего нужен в двух случаях:
1. **Экспортный контур** — если контрагент в цепочке EU-заказчика, его
   неготовность по CSDDD/CBAM станет вашей проблемой через контракт.
2. **Производство** — экологические обязательства и предписания надзоров
   превращаются в деньги (платежи, приостановки, судебные расходы).

В остальных случаях домен закрывается на уровне «рисков не выявлено» без
присвоения оценки — имитировать ESG-скоринг по открытым данным нельзя.

## Частые ошибки

1. **Присваивать рейтинг там, где его нет** — выдуманный ESG-балл хуже его отсутствия.
2. **Считать отсутствие рейтинга риском** — для частной компании это норма.
3. **Игнорировать экспортный контур** — самый недооценённый риск среднего бизнеса.
4. **Смешивать ESG с корпоративным управлением** — управление разбирается в домене
   `02` (заинтересованность, крупные сделки), здесь только срез.
5. **Читать ESG-страницу сайта как факт** — сверять с реестрами проверок.
