# Санкционный скрининг и комплаенс

Обязательный домен. **Ошибка в санкционном скрининге может привести к блокировке активов, уголовному преследованию и вторичным санкциям против собственной организации.** Санкции США/ЕС/Великобритании имеют экстерриториальное действие — применяются к не-американским и не-европейским компаниям, если те взаимодействуют с подсанкционными лицами.

## Списки для проверки

| Список | Регион | Юрисдикция | Правило блокировки |
|--------|--------|-------------|---------------------|
| **OFAC SDN** | США | Экстерриториально (USD-транзакции, US-персоны) | **50% Rule** (см. ниже) |
| **EU Consolidated List** (Reg. 269/2014) | ЕС | Экстерриториально (EU-персоны, EU-территория) | "Контроль" (менее механичный, чем OFAC) |
| **UK OFSI Consolidated List** | UK | Пост-Брекзит, не всегда синхронно с ЕС | "Контроль" + OFSI guidance |
| **UN Sanctions** | Глобально | Все государства-члены | Включены в национальные списки |
| **OpenSanctions** | Агрегатор | Глобально | Объединяет все списки + PEP + EGRUL |
| **NS-CMIC** (Китай) | US | Китайские military-linked | Только для US-персон |
| **Приложение IV Reg. 833/2014** | ЕС | Российские + посредники (Турция, ОАЭ, Казахстан, КНР, Узбекистан) | Усиленные экспортные ограничения |

## Платформы (открытые → коммерческие)

### Tier 1 — обязательные (бесплатно)

```bash
# OpenSanctions — основной агрегатор
web_extract "https://opensanctions.org/search/?q=$КОМПАНИЯ_ИЛИ_ФИО"
web_extract "https://opensanctions.org/search/?q=$ФИО+$ГОД_РОЖДЕНИЯ"

# OFAC SDN напрямую
web_extract "https://sanctionssearch.ofac.treas.gov/Details.aspx?id=$ID"

# EU Consolidated
web_search "$NAME EU sanctions Regulation 269/2014"

# UK OFSI
web_search "$NAME UK sanctions OFSI consolidated"
```

### Tier 2 — коммерческие (если есть доступ)

- **ComplyAdvantage** — единый поиск + AML + adverse media
- **Kharon** — специализация РФ/Иран/КНДР, отслеживает сети обхода санкций
- **Dow Jones Risk & Compliance** — PEP + санкции + adverse media
- **Refinitiv World-Check (LSEG)** — стандарт для KYC/AML
- **LexisNexis WorldCompliance**
- **Sumsub** — KYC/KYB, сильное покрытие СНГ

### Tier 3 — специализированные (для РФ)

- **checko.ru** — если есть ключ, проверяет бенефициаров + связанных лиц
- **СПАРК-Интерфакс** — российские санкционные списки, бенефициарные цепочки
- **Контур.Фокус** — аналог

## OFAC 50% Rule (КРИТИЧНО)

**Правило:** любое юрлицо, в котором одно или более лиц из SDN владеет (прямо/косвенно, в совокупности) ≥50%, **само считается заблокированным** — даже если не поименовано в SDN.

### Методология

```
1. Идентифицировать всех бенефициаров цели (прямых и косвенных) >25%
2. Проверить каждого по OFAC SDN
3. Если владелец — юрлицо, повторить процесс для его владельцев
4. Суммировать доли всех SDN-лиц на каждом уровне цепочки
5. Если совокупная доля SDN ≥ 50% на ЛЮБОМ уровне → компания заблокирована
6. Рекурсивно: если родительская компания 50%+ в SDN, она И все её дочки заблокированы
```

### Пример

```
Олигарх SDN → владеет 30% компании A
             → владеет 30% компании B
Компания A (30%) + Компания B (25%) → владеют 55% целевой компании X

Целевая компания X — ЗАБЛОКИРОВАНА (55% через A+B, даже если прямая доля SDN 0%)
```

## PEP (политически значимые лица)

**Кто считается PEP:** главы государств, министры, парламентарии, высшие судьи, руководители ЦБ, послы, руководители госкомпаний, члены семей и близкие партнёры. Срок: 12 мес после ухода с должности (по рекомендации FATF, может быть дольше).

```bash
# Поиск PEP
web_search "\"$ФИО\" (PEP OR \"политически значимое\" OR депутат OR министр OR губернатор OR сенатор)"
opensanctions_check $ФИО  # OpenSanctions включает PEP-данные
```

PEP-статус сам по себе ≠ блокировка, но это **enhanced due diligence** (усиленная проверка) — нужны дополнительные обоснования сделки.

## Проверка для российских контрагентов: 115-ФЗ

Федеральный закон № 115-ФЗ «О противодействии легализации доходов» — основа российского AML/CFT.

**Обязанности контрагента:**
- Идентификация бенефициаров (>25%)
- Мониторинг операций ≥600 000 ₽
- Сообщения в Росфинмониторинг о подозрительных операциях
- Хранение KYC/CDD ≥5 лет

**Штрафы:** компания 100-500K ₽, руководитель 30-40K ₽ (небольшие, но репутационный ущерб + уголовка при повторах).

## Экспортный контроль

### США
- **ITAR** (International Traffic in Arms Regulations) — вооружения
- **EAR** (Export Administration Regulations) — товары двойного назначения
- **BIS Entity List**, **Denied Persons List**

### ЕС
- **Dual-Use Regulation 2021/821** — товары двойного назначения
- **Annex IV Reg. 833/2014** — российские + посредники (Турция, ОАЭ, Казахстан, КНР, Израиль, Сербия, Вьетнам, Узбекистан)

### Когда проверять

- Если контрагент торгует электроникой, микрочипами, телеком-оборудованием, ПО, шифрованием
- Если есть конечные получатели в Иране, Сирии, КНДР, подсанкционных регионах
- Если сделка связана с оборонкой, аэрокосмосом, sensitive technologies

## Команды для агента

```bash
# 1. OpenSanctions по названию компании
web_extract "https://opensanctions.org/search/?q=$COMPANY_NAME"

# 2. OpenSanctions по ИНН (если российское юрлицо)
web_extract "https://opensanctions.org/search/?q=$INN"

# 3. OpenSanctions по каждому бенефициару
for PERSON in "$BO1" "$BO2" "$BO3"; do
  web_extract "https://opensanctions.org/search/?q=$PERSON"
done

# 4. OFAC SDN (если есть подозрение на US-связи)
web_extract "https://sanctionssearch.ofac.treas.gov/Details.aspx?id=$ID"

# 5. EU sanctions map
web_extract "https://www.sanctionsmap.eu" --filter "$COUNTRY"

# 6. Проверка Annex IV (если российский контекст + посредники)
web_search "$COMPANY \"Annex IV\" 833/2014"

# 7. Проверка PEP через Google
web_search "\"$ФIO\" (PEP OR министр OR депутат OR губернатор OR сенатор OR \"совета директоров\" гос)"

# 8. Adverse media
web_search "\"$COMPANY\" (fraud OR corruption OR bribery OR мошенничество OR коррупция OR взятка)"
```

## Красные флаги

### CRITICAL (сделка невозможна)
- **Прямое совпадение** с OFAC SDN/EU/UK/UN любого лица в цепочке владения
- **OFAC 50% Rule срабатывает** (агрегированная доля SDN ≥ 50% на любом уровне)
- **Контрагент в Annex IV** при попытке экспорта dual-use товаров в ЕС
- **Санкционный режим страны**, с которой связана сделка (Иран, КНДР, Сирия)

### HIGH (требует enhanced DD)
- **Косвенная связь** с SDN через сети обхода (Kharon, ComplyAdvantage)
- **PEP-статус** ключевого лица
- **Член совета директоров** компании под секторальными санкциями (SSI)
- **Географический риск**: посредники из Турции, ОАЭ, Казахстана, Кыргызстана, Армении, Грузии (для российского контекста)
- **Отсутствие AML/CFT процедур** (особенно для РФ-контрагентов по 115-ФЗ)

### MEDIUM
- **Недавняя (1-2 года) смена** владельца, попадавшего в санкционные списки
- **Совпадение ФИО** (но не birthdate) с SDN — требует ручной проверки
- **Публичные упоминания** в СМИ в контексте санкций (без формального включения в список)

## Частые ошибки

1. **Проверить только компанию, не бенефициаров** — главная ошибка. Идти до физлица.
2. **Не применить OFAC 50% Rule** — даже если компания чистая, агрегированная доля SDN через посредников может блокировать.
3. **Довериться OpenSanctions как единственному источнику** — задержка 24-48 ч, не самые свежие списки.
4. **Пропустить проверку PEP** — это не блокировка, но enhanced DD обязательна.
5. **Не проверить адрес доставки/получателя** — компания чистая, но товар идёт в Иран через ОАЭ.
6. **Забыть экспортный контроль** — особенно для электроники, микрочипов, телеком-оборудования.
7. **Не проверить affiliated companies** — у крупных групп дочки тоже под санкциями.

## Проверка после сделки

Санкционный скрининг — **не событие, а процесс**. После сделки:

- Настроить ежемесячную проверку OpenSanctions по всем бенефициарам
- Подписаться на обновления OFAC SDN (https://ofac.treasury.gov/rss-feed)
- При попадании в список — немедленно ntfy `vector-legal-deadlines` priority=max
- Пересмотреть все текущие договоры с контрагентом
