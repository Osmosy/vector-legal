# Реестры, государственные базы и бенефициары (РФ-приоритет)

Главный домен DD для российских юрлиц и ИП. Покрывает 70% практики. Для не-РФ целей используй этот файл как шаблон, заменив источники на Companies House / SEC EDGAR / GSXT.

## Источники (по приоритету)

### Tier 1 — первичные реестры (всегда)

| Источник | URL | Что даёт | Когда |
|----------|-----|----------|-------|
| **EGRUL** (ФНС) | https://egrul.nalog.ru | ОГРН, ИНН, КПП, статус, адрес, директор, учредители, ОКВЭД, история изменений, размер уставного капитала | **всегда** |
| **Реестр дисквалифицированных лиц** | https://service.nalog.ru/disqualified.html | ФИО лиц, которым суд запретил руководить | всегда для директоров и учредителей |
| **Реестр доверенностей (нотариат)** | https://reestr-dover.ru | Проверка подлинности нотариальных доверенностей | если контрагент действует по доверенности |
| **ФССП** (исполнительные производства) | https://fssp.gov.ru/iss | Долги по ИП юрлица и ФИО | всегда |
| **Картотека арбитражных дел** | https://kad.arbitr.ru | Арбитражные споры (экономические) | всегда по ИНН и ФИО |
| **Федресурс** (банкротства) | https://bankrot.fedresurs.ru | Сообщения о банкротстве, намерения, торги | всегда |
| **ГИР БО** (бухотчётность) | https://bo.nalog.gov.ru | Баланс, ОФР, ОДДС за несколько лет | всегда (если есть отчётность) |

## Команды для агента

### Express (быстрый скрининг)

```bash
# 1. EGRUL по ИНН (предпочтительно через checko, если ключ есть)
curl -s "https://egrul.nalog.ru/api/search?query=$INN" | jq
# Если API возвращает капчу — переключиться на web_extract через browser-os-emulation

# 2. Альтернатива — checko.ru одной командой (если есть ключ)
# Используй скрипт: checko-contractor-check/scripts/check.py ИНН
# Скилл есть в vector-work, формат: JSON со всеми реестрами сразу

# 3. Реестр дисквалификации — для каждого ФИО директора/учредителя
curl -s "https://service.nalog.ru/disqualified.html?search=$FIO" -G

# 4. ФССП — поиск исполнительных производств
curl -s "https://fssp.gov.ru/iss/search?is=$INN&type=legal" -G
# И по ФИО: is=Иванов+Иван+Иванович

# 5. kad.arbitr — поиск по ИНН
# URL: https://kad.arbitr.ru/?search=search&caseType=&caseNumber=&court=&dateFrom=&dateTo=&sides=$INN
# (это UI, нужен browser-os-emulation или web_extract)
web_extract "https://kad.arbitr.ru/?sides=$INN" --filter "case summary"

# 6. Федресурс — банкротство
web_extract "https://bankrot.fedresurs.ru/?searchString=$INN"

# 7. ГИР БО — бухотчётность (если ОГРН известен)
web_extract "https://bo.nalog.gov.ru/bfo/$OGRN"
```

### Standard — бенефициары и цепочки

```bash
# Проверка каждого бенефициара >25% в OpenSanctions
web_extract "https://opensanctions.org/search/?q=$ФИО+$ГОД_РОЖДЕНИЯ"

# Если бенефициар — юрлицо: рекурсивно проверить его владельцев
# До 5 уровней вложенности — на каждом уровне проверка OpenSanctions

# Поиск номинальности: один и тот же директор в десятках компаний
web_extract "https://rusprofile.ru/search?query=$ДИРЕКТОР_ФИО&type=director"
```

## Красные флаги (RF-специфика)

### Critical
- **Прямое попадание в санкционные списки** (OFAC, EU, UK) — даже для российского юрлица
- **Уголовное преследование** руководителя/учредителя (sudrf.ru, СПАРК)
- **Действующее производство по банкротству** самого юрлица

### High
- **Массовый адрес регистрации** (10+ компаний на одном адресе) — признак номинальности
- **Номинальный директор** (директор 10+ других юрлиц, особенно в стадии ликвидации)
- **Отсутствие бенефициаров в ЕГРЮЛ** (юрлицо обязано раскрывать по 115-ФЗ)
- **Уставный капитал 10K ₽ при обороте 50M+ ₽** — риск вывода активов
- **Недавняя (3-6 мес) смена владельцев** перед сделкой — возможна подготовка к фиктивному банкротству
- **Смена адреса в массовый регион** (Москва-Сити, БЦ на Садовом) — возможна подготовка к номиналу
- **Связь с Приложением IV Регламента 833/2014** (EU Annex IV) — усиленные экспортные ограничения
- **Проигранные иски на сумму >50% уставного капитала** — финансовая несостоятельность

### Medium
- **Иски на взыскание задолженности >10% оборота** — проблемы с ликвидностью
- **Текущие исполнительные производства** < 1 млн ₽
- **Убыток последнего отчётного периода** при отсутствии истории убытков
- **Смена директора за последние 6 мес** без объяснения
- **Юридический адрес ≠ фактический** (где находятся сотрудники)

### Low
- **Незначительные иски** (1-2, суммы <100K ₽)
- **Мелкие ИП в ФССП** (штрафы, налоговые доначисления)
- **Небольшое несовпадение данных** (опечатки в ОКВЭД, разночтения в адресе)

## 115-ФЗ compliance (вопросы для контрагента)

Запросить у компании (формально обязаны по 115-ФЗ):

1. Назначен ли ответственный за AML/CFT?
2. Как ведётся идентификация клиентов и бенефициаров? (правила внутреннего контроля)
3. Хранятся ли данные KYC 5+ лет?
4. Обновляются ли сведения о бенефициарах ежегодно?
5. Были ли запросы от Росфинмониторинга?
6. Есть ли подозрительные операции, о которых сообщали?

## Частые ошибки

1. **Не проверить ФИО бенефициара в OpenSanctions** — даже если само юрлицо чисто.
2. **Остановиться на первом уровне владения** — пройти до физлица, не до офшора.
3. **Не проверить kad.arbitr по ФИО директора/учредителей** — у них могут быть долги в других юрлицах.
4. **Довериться одному источнику** — перекрёстно проверить ЕГРЮЛ + сайт + суды + масс-адрес.
5. **Забыть реестр дисквалификации** — если директор в нём, контрагент не может действовать.
6. **Считать массовый адрес неважным** — это топ-1 признак номинальности.
7. **Не проверить бывших учредителей** — могли вывести долю перед банкротством.
8. **Игнорировать 115-ФЗ** — это не «формальность», а зона риска для самого покупателя.

## Связь с checko.ru API

Если в `~/.hermes/.env` есть `CHECKO_API_KEY`, **предпочтительно** использовать checko.ru одной командой — он агрегирует ЕГРЮЛ + госконтракты + суды + ИП + банкротство + финансы в одном JSON.

Скрипт: `~/.hermes/skills/finance/checko-contractor-check/scripts/check.py ИНН`

Если скрипт недоступен, используй `web_extract` на `https://checko.ru/company/$INN` — это даст 80% того, что нужно, в одном месте.
