# /customize — правка practice profile

## Когда запускается

Пользователь хочет изменить что-то в practice profile — риск-постур, контакт
эскалации, позицию playbook, юрисдикцию, формат выхода — без перезапуска всего
cold-start интервью и без ручной правки файла.

## Что делать

1. **Прочитать конфиг.** `~/.hermes/legal/commercial-legal/CLAUDE.md` (и
   `~/.hermes/legal/company-profile.md` уровнем выше). Если плагин не
   настроен и есть `[PLACEHOLDER]` — сказать:

   > Setup ещё не запускался. Сначала `cold-start-interview` — customize
   > предназначен для правки уже существующего профиля.

2. **Показать карту правок.** Секции профиля сгруппированы, текущее значение
   одной строкой:

   - **Компания** — название, индустрия, юрисдикции, stage, practice setting,
     сторона (продажи/закупки) *(общий company-profile.md — изменения
     применяются ко всем плагинам Vector Legal)*
   - **Риск-постур** — консервативный / средний / агрессивный; что это значит
     для фоллбэков и триггеров эскалаций
   - **Люди** — цепочка эскалаций, аппруверы по денежному порогу и типу пункта
   - **Позиции playbook** — лимиты ответственности, indemnity, IP, 152-ФЗ,
     расторжение, автопродление, повышение цен + фоллбэки для каждой
   - **NDA triage preferences** — что GREEN / YELLOW / RED для входящих NDA
   - **Review preferences** — стиль redline, глубина объяснений, auto-
     stakeholder-summary on/off
   - **House style** — формат документа, блок подписи, renewal-канал, формат
     deviation-log
   - **Интеграции** — ЭДО, ЭП, Telegram, правовые базы
   - **Matter workspaces** — пути, cadence renewal-watcher

3. **Прочитать текущее значение выбранной секции** — процитировать, чтобы
   юрист видел то, что меняют.

4. **Спросить новое значение.** Одно поле за раз.

5. **Показать diff** (старое → новое) **и ждать подтверждения.**

6. **Записать** в practice profile.

7. **Показать подтверждение** + одну строку: «Изменение затронет [какие
   навыки/выходы]».

## Конвенции

- **Одно поле за одну правку.** «Измени риск-постур» и «обнови матрицу
  эскалаций» — два вызова, не один.
- **Цитировать перед изменением.** Юрист должен увидеть, что меняется.
- **Подтверждать перед записью.** Показать diff, ждать yes.
- **Обновить verification log** при изменении порога или факта: `[дата]
  [поле: старое → новое] изменено [кем]`.
- **Не изменять seed documents.** Они — то, из чего playbook извлечён;
  изменение seed-таблицы — только через `--redo`.

## Типовые правки

- «Поменяй риск-постур на консервативный» → пересчитать все фоллбэки и
  автотриггеры под новый постур; показать, что изменится, до записи.
- «Эскалация >X — теперь к [Имя]» → обновить матрицу эскалаций.
- «Playbook: неограниченную ответственность всегда эскалировать» → добавить
  в автоматические эскалации.
- «Renewal-алерты в Telegram канал @X» → обновить House style.
