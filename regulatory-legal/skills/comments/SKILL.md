# /comments — комментарии на проекты НПА

## Purpose

Проекты НПА (публичные обсуждения — regulation.gov.ru, порталы ведомств)
влияют на будущее компании. Этот навык: (1) показывает открытые
обсуждения по watchlist с дедлайнами, (2) логирует решения
комментировать/нет, (3) готовит черновики отзывов.

## Загрузить контекст

`~/.hermes/legal/regulatory-legal/CLAUDE.md` — watchlist, comment tracking
(включён ли), дефолтный владелец решений.

## Default view — открытые обсуждения

Проверить источники: regulation.gov.ru (web_search по ведомству-инициатору,
`[web search — verify]`), отраслевые порталы. Для каждого:

```markdown
[TIER HEADER]

# Comment Period Tracker — [дата]

### ⏰ Дедлайн < 14 дней
| Проект | Ведомство | Дедлайн | Владелец | Статус решения |
|---|---|---|---|---|

### 🟡 Открыто (> 14 дней)
[Та же таблица]

### Недавно завершённые
[Что было, что решили, итог — если известен]
```

`Status решения` из comment-tracker:
`~/.hermes/legal/regulatory-legal/comment-tracker.yaml`:

```yaml
- id: CM-004
  rule: "[Проект приказа — реквизиты]"
  initiator: "[ведомство]"
  deadline: 2026-09-30
  owner: [дефолтный владелец или назначенный]
  status: undecided   # undecided | comment_planned | comment_submitted | no_comment | monitoring
  notes: ""
```

## Log a decision (`--log`)

«По [проекту] решили: комментируем / не комментируем / мониторим» —
обновить статус + кто решил + почему (одна строка). Consequential gate:
решение «не комментируем» по проекту с существенным влиянием —
подтвердить явно.

## Черновик отзыва

Для `comment_planned`:

1. Реквизиты проекта: `[verify]` по regulation.gov.ru (номер публикации,
   дедлайн, кто принимает)
2. Суть изменения и затрагиваемая практика компании (relevance hook из
   профиля)
3. Формат отзыва: конкретные пункты проекта → предлагаемые правки →
   обоснование (практика, затраты, противоречия вышестоящим актам).
   Тон деловой, без эмоций; ссылки на нормы с тегами
4. Перед отправкой — consequential gate: отправка в ведомство — внешнее
   действие; финальный текст утверждает юрист/владелец, отправка — вне
   плагина (через форму regulation.gov.ru)

## Notifications

Если cron настроен и comment tracking включён: напоминание за 14 и за
3 дня до дедлайна по undecided (в Telegram/House-style канал). Без cron —
показывать в каждом запуске `comments` секцию «скоро дедлайны».

## Consequential-action gate

Отправка позиции регулятору = внешнему действию от имени компании.
Навык готовит драфт; отправку делает человек. Всегда:
> Финальный текст и отправку подтверждаешь ты — отправки со стороны
> плагина не будет (формы требуют авторизации).

## Comments

Регуляторные дедлайны и реквизиты проектов — из web/regulation.gov.ru,
всегда `[verify]` до действий; реквизиты НПА сверять по pravo.gov.ru.
Каждый выход — с блоком `⚠️ Reviewer note` (источники, покрытие,
флаги, перед опорой на вывод) по формату practice profile.

## Что этот навык не делает

Не оценивает «шансы проекта» и не предсказывает принятие; не подаёт
комментарии сам; не заменяет позицию юриста по существу норм.
