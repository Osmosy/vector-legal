# /customize — правка practice profile Regulatory

## Когда запускается

Пользователь хочет изменить что-то в профиле регуляторного монитора —
добавить ведомство, сменить порог, указать библиотеку политик — без
перезапуска интервью.

## Что делать

1. **Прочитать конфиг** `~/.hermes/legal/regulatory-legal/CLAUDE.md`
   (и `~/.hermes/legal/company-profile.md`). Плейсхолдеры →

   > Setup не запускался. Сначала `cold-start-interview`.

2. **Показать карту правок:**

   - **Watchlist** — регуляторы/темы и их источники
   - **Materiality threshold** — что «всегда важно» / «обзорно» / FYI,
     денежные пороги
   - **Отрасль и гильотина** — отрасль пользователя, следим ли за
     отменой требований (ПП №1128), 44-ФЗ/223-ФЗ
   - **Библиотека политик** — пути, владельцы, даты пересмотра
   - **Feed configuration** — источники, темы, каденс
   - **Comment tracking** — включён ли, владелец решений
   - **Интеграции** — cron, Telegram, хранилище, базы
   - **Matter workspaces** — для firm-практик

3. **Процитировать текущее значение.**

4. **Спросить новое значение.** Одно поле за раз.

5. **Показать diff и ждать подтверждения.**

6. **Записать** + подтверждение «Изменение затронет: [навыки]».

## Конвенции

- Одно поле за правку; цитировать до изменения; подтверждать до записи
- Обновлять verification log при изменении порогов
- Новый фид — только если проверяем источник (тест-запрос web_search);
  непроверенный — ⚪ с пометкой
- Не изменять секцию seed-документов (её меняет только `--redo`)

## Типовые правки

- «Добавь Россельхознадзор в watchlist» → спросить: почему (надзор/
  сертификация?), какой источник ловим (сайт/базы), в какую материальность
  попадают их акты по умолчанию
- «Проекты НПА теперь — всегда важно» → сменить тип в materiality +
  предупредить, что comment-tracker будет плотнее
- «Библиотека переехала в /legal/policies» → обновить путь в профиле;
  policy-diff/policy-redraft начнут читать оттуда
- «Дайджест — по понедельникам» → обновить feed config cadence; напомнить
  про cron (если ✗ — не придут автоматически)
