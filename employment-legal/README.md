# Employment Counsel — Трудовое право (Vector Legal)

Адаптация [claude-for-legal/employment-legal](https://github.com/anthropics/claude-for-legal)
(Anthropic, Apache-2.0) под **Трудовой кодекс РФ** и Hermes Agent.

## Что это

In-house сопровождение трудовых решений: оффер/трудовой договор со всеми
обязательными условиями ст. 57 ТК, проверка увольнения против закрытого
перечня ст. 81 ТК с процедурой по каждому основанию, переквалификация ГПХ
в трудовые отношения (ст. 15, 19.1 ТК + Постановление Пленума ВС №15 от
29.05.2018), ЛНА, отпуска, служебные расследования, приём иностранцев.

Выход — memo, которое юрист проходит за один проход. Не юридическая
консультация.

## ⚠️ Юридический дисклеймер (канонический)

**Всё, что производит плагин, — черновик для проверки юристом.** Не
юридическая консультация, не правовое заключение, не замена юриста. Каждый
документ требует проверки квалифицированным специалистом. Источники
указываются явно.

## Главный флаг ТК РФ (во всех навыках)

**Ат-вилл (at-will employment) в РФ не существует.** Уволить можно только по
основанию из закрытого перечня ст. 77–83 ТК, чаще всего — ст. 81, и каждый
раз с императивной процедурой, где нарушение порядка = восстановление
сотрудника судом (ст. 394 ТК) + оплата вынужденного прогула + средний
заработок за время задержки исполнения. Плюс административная ответственность
работодателя по ст. 5.27 КоАП (ч. 1 — нарушение трудового законодательства:
10–50 тыс. руб. для юрлиц; за повторное — до 70 тыс.). «Просто расстаёмся с
оплатой пары недель» не работает: нельзя уволить по основанию, которого нет в
перечне, и нельзя заменить основание деньгами «для скорости». Если навык
видит запрос в духе at-will — останавливается и спрашивает, какое основание
из ТК предполагается.

```
    ├── hiring-review/             # Оффер/трудовой договор: ст. 57, 70, 59
    ├── termination-review/        # Увольнение: ст. 77–83 (процедуры ст. 81)
    ├── worker-classification/     # ГПХ-vs-трудовой: переквалификация
    ├── wage-hour-qa/              # Оплата труда: МРОТ, ст. 152–154

    ├── handbook-updates/          # Изменения ЛНА: ст. 22, 74 ТК
    ├── leave-tracker/             # Сроки по отпускам/больничным
    ├── log-leave/                 # Регистрация отпуска/больничного
    ├── investigation-open/        # Открыть служебное расследование
    ├── investigation-add/         # Добавить материалы (акты, объяснения)
    ├── investigation-query/       # Вопросы по логу расследования
    ├── investigation-summary/     # Аудиторские версии итога
    ├── investigation-memo/        # Итоговое заключение по логу
    ├── internal-investigation/    # Референс-фреймворк (для investigation-*)
    ├── international-expansion/   # Референс: приём иностранцев (ФЗ-115)
    ├── expansion-kickoff/         # Открыть трекер найма иностранцев/юрисдикции
    └── expansion-update/          # Обновить трекер
```

## Быстрый старт

```
cold-start-interview          # 5–10 мин — пишет practice profile
termination-review <сценарий> # Проверка увольнения против ст. 81 ТК
hiring-review <оффер>         # Оффер/трудовой договор против ст. 57
```

До cold-start все навыки работают в **provisional mode**: generic дефолты
(ТК РФ, средний риск-аппетит) с меткой `[PROVISIONAL]`.

## Practice profile

Конфигурация живёт в `~/.hermes/legal/employment-legal/CLAUDE.md`. Шаблон —
`CLAUDE.md` в корне плагина. Профиль содержит: роль пользователя (юрист /
не-юрист), штат и ЛНА компании, матрицу полномочий HR/юрист/директор,
эскалации, house style, seed-документы.

### Право Российской Федерации (базовые замены против US-версии)

| CFL (US) | Vector Legal (RU) |
|---|---|
| At-will employment | **Ат-вилл не существует**: закрытый перечень оснований ст. 77–83 ТК; ст. 81 — только по основаниям и процедурам статьи |
| Employment at will / just cause | Ст. 81 ТК: общие основания (п. 1–3, 5–13) + отдельные для категорий; процедурные требования императивны |
| Offer letter (single doc) | Трудовой договор — письменный, обязательные условия ст. 57 ТК; оффер — не юридический документ, оферта с 3 днями на акцепт (ст. 443 ГК по аналогии не применяется; до подписания договор не действует) |
| Probation by default | Испытательный срок — только если установлен соглашением ст. 70 ТК: до 6 мес. (руководители и главбухи), 3 мес. остальные; запрещён отдельным категориям (беременные, до 18 лет, первые по диплому и др.) |
| Non-compete / at-will covenants | **Запрещены ст. 9, 37 Конституции и ТК**: неконкуренция сотрудников невозможна; соглашение о неразглашении допустимо только в рамках ФЗ-98 о КТ с фактическим введением режима |
| Severance packages | Выходное пособие — только по ст. 178 ТК (ликвидация/сокращение — средний заработок 2 мес., при сокращении в организации с численностью <25%… см. навык), иначе — нет обязанности; «severance в обмен на release» не работает по ТК, кроме отдельных случаев |
| OWBPA / release periods | Отпуск по уходу до 3 лет (ст. 256), пособия по нетрудоспособности от СФР, компенсация неиспользованного отпуска (ст. 127, 140) — расчёт при увольнении |
| FLSA exempt/non-exempt | Ст. 152–154 ТК: сверхурочные — первые 2 часа ×1,5, далее ×2; ночные ×20%; выходные ×2 или отгул; нормальная продолжительность 40 ч/нед (ст. 91) |
| EEOC / state FEHA | Ст. 64 ТК (запрет отказа по обстоятельствам вне деловых качеств), ст. 261 (защита при увольнении отдельных категорий), ст. 379 (самозащита) |
| E-Verify / I-9 | ФЗ-115: патент/РВП/ВНЖ, ВКС — уведомление МВД, договор с ВКС в течение 3 дней |
| WARN Act (mass layoff) | Сокращение численности/штата: массовое увольнение — критерии ПП РФ №99; увольнение по п. 1–2 ч. 1 ст. 81 с уведомлением за 2 мес. (ст. 180), преимущественное право (ст. 179) |

### Штрафы за нарушение ТК (ст. 5.27 КоАП)

| Нарушение | Часть ст. 5.27 | Штраф юрлицу |
|---|---|---|
| Всякое нарушение ТК (дополнительно) | ч. 1 | 30–50 тыс. руб. |
| Нарушение при заключении/изменении/расторжении договора | ч. 4 | 10–100 тыс. руб. |
| Уклонение от оформления (ГПХ вместо трудового) | ч. 4 | до 100 тыс. + доначисления взносов |
| Повторное нарушение | ч. 5 | 50–70 тыс. руб. |
| Невыплата заработной платы | ч. 6 | 30–50 тыс. (повторно — 50–100 тыс.) |
| Нарушение правил привлечения иностранцев | ст. 18.15 | отдельная статья — до 1 млн для юрлиц по отдельным составам |

## Provisional mode

До cold-start навыки работают с generic дефолтами: ТК РФ, средний риск
(штрафы ст. 5.27 КоАП как базовая оценка), lawyer role. Каждый выход помечается
`[PROVISIONAL — запусти cold-start-interview для калибровки]`.

## Отличия от CFL

1. Право РФ вместо US: ТК РФ вместо FLSA/At-will; закрытый перечень оснований
   увольнения вместо at-will/just-cause; неконкуренция запрещена вместо
   non-compete по штатам
2. Пути: `~/.hermes/legal/employment-legal/` вместо `~/.claude/plugins/config/...`
3. Интеграции: HRIS (Workday → HR-Модуль 1С / СБИС ERP — если настроен; иначе
   leave-register.yaml); правовые базы — КонсультантПлюс/Гарант через
   web_search + `[verify]` (официального MCP нет)
4. CourtListener → kad.arbitr.ru (картотека); судебная практика по трудовым
   спорам — Пленумы ВС, обзоры, Обзор практики по спорам об увольнении
5. Slack → Telegram через Hermes gateway; State WARN → массовое сокращение
   (критерии территориальных органов Роструда)
