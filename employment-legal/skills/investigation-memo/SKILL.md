# /investigation-memo — итоговое заключение по расследованию

Загружает фреймворк `internal-investigation` (Mode 4 Memo).

## Инструкции

1. **Идентифицировать расследование**, прочитать log.md + sources.md
   (coverage!). Если лог пуст/крошечный — сказать, что memo рано, и
   показать, чего не хватает.
2. **Если memo.md есть** — прочитать, обновить дельтой: что изменилось,
   не стереть прежние выводы без обоснования (история пересмотров —
   в конце memo changelog).
3. **Собрать memo по структуре Mode 4:**
   - Вывод по каждому allegation (подтверждается / частично / нет) + уровень
     уверенности
   - Хронология с цитатами записей лога
   - Факты → доказательства → противоречия по каждому аспекту
   - **Квалификация по ТК:** нарушение обязанностей? взыскание по ст. 192
     (замечание/выговор/увольнение + п. ч. 1 ст. 81) → cross-check
     `termination-review` (категории ст. 261, ч. 6 ст. 81!)
   - **Процедурный чеклист ст. 193:** акт → требование объяснений → 2
     рабочих дня → приказ → ознакомление 3 дня `[verify]` — сделано/нет
   - Риски: реталиация, ПДн, репутация, проверка ГИТ, коллективка
   - Рекомендации: взыскание / отказ / процесс-фикс → policy-drafting
4. **Каждый факт — ссылка на запись лога.** Факт без ссылки — удалить или
   пометить `[verify]`.
5. **Header** — по профилю + строка расследования
   (`СЛУЖЕБНОЕ РАССЛЕДОВАНИЕ — ДОСТУП ОГРАНИЧЕН`), **reviewer note** — по
   профилю, coverage в строке «Прочитано».
6. **Decision tree в конце** (draft опций): взыскание / отказ / дальше
   собирать / эскалация / другое.

## Правила

- Догадка ≠ вывод; «уверенность» — по надёжности доказательств (Mode 3).
- Не квалифицировать деяние как преступление (это для следствия) —
  только ТК-квалификация + рекомендация «сообщить в полицию» при
  признаках `[review]`.
- Процедурные нарушения ст. 193 фиксировать честно: «срок истёк», «акт
  без свидетелей» — это риск проигрыша спора, не косметика.

## What this skill does not do

- Не выносит приказ о взыскании (директор), не ведёт разговор.
- Не гарантирует итог спора — собирает доказательную базу и процедуру.
