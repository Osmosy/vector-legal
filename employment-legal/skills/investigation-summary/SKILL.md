# /investigation-summary — адресные версии по расследованию

Загружает фреймворк `internal-investigation` (Mode 5 Summary).

## Инструкции

1. **Проверить memo** (`memo.md` в папке расследования). Если memo нет —
   сначала investigation-memo: summary собирается из memo, не из лога
   напрямую.
2. **Спросить аудиторию, если не указана.** Профили:

| Аудитория | Содержит | Исключает |
|---|---|---|
| **HR** | факты, доказательства, рекомендация по взысканию, процедурные шаги и сроки ст. 193 | оценка уверенности, юридические риски, адвокатские пометки, ПДн третьих лиц |
| **Руководство** | вывод одной строкой, бизнес-эффект, решение, что нужно от руководства | детали показаний, ПДн, квалификация |
| **Внешний адвокат/ГИТ-ответ** | полный контекст, доказательства, риски, приложения | ничего — полная версия |

3. **Собрать новый документ** (не вырезки из memo): header, короткий
   вывод, только то, что нужно этой аудитории, next steps.
4. **Header по аудитории:** HR/руководство — `КОНФИДЕНЦИАЛЬНО —
   СЛУЖЕБНОЕ РАССЛЕДОВАНИЕ — [аудитория]`; внешний адвокат — полная
   версия с полным header профиля + передать режим защиты.
5. **Destination check обязателен:** куда пойдёт документ; канал e-mail
   «на весь отдел» — снимает ограничение доступа → предупредить и
   предложить два варианта.
6. **ПДн-минимизация:** имена третьих лиц — замещать ролями
   («свидетель-1») в версии для руководства; ФИО только там, где
   юридически необходимо (приказ о взыскании).

## Что ломается чаще всего

- Руководство просит «поименовать всех» в версии для совета — отказ или
  ролевые псевдонимы `[review]`.
- HR-версия уезжает в общий диск — destination check + пометка о режиме
  КТ/ограниченном доступе в теле документа.

## What this skill does not do

- Не создаёт memo (investigation-memo).
- Не рассылает ничего — только готовит документ и показывает риски
  канала.
