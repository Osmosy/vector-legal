# /investigation-query — вопросы по логу расследования

Загружает фреймворк `internal-investigation` (Mode 3 Query).

## Инструкции

1. **Идентифицировать расследование** по slug. Прочитать log.md целиком
   (если >50 записей — сначала индекс, затем целевые записи; покрытие
   зафиксировать в reviewer note).
2. **Ответить по разделам Mode 3:**
   - Что говорят по вопросу (с цитатами записей: дата + source)
   - Где противоречия (⇄-записи, конфликт показаний)
   - Чего не хватает (sources.md pending)
   - Сильнейшее доказательство по каждому аспекту (акт ≥2 подписей >
     опрос > наблюдение > слух)
3. **Только по логу.** Чего в логе нет — «по логу данных нет», не
   додумывать. Если пользователь ссылается на факт вне лога — предложить
   добавить через investigation-add.
4. **Таймлайн:** для вопросов по хронологии (кто знал раньше, когда
   узнал) строить мини-таймлайн из timestamp-ов записей.
5. **Сроки по ТК РФ:** если вопрос касается сроков — напомнить рамки
   ст. 193 ТК: объяснения — **2 рабочих дня** с момента требования
   `[model knowledge — verify]`; взыскание — не позднее 1 мес. со дня
   обнаружения; процедура взыскания — акт → требование → приказ.

## Shared guardrails (канон — practice profile)

**Reviewer note / decision tree / Destination check / Provenance /
No-silent-supplement / Currency trigger / Large input** — см.
practice profile (`~/.hermes/legal/<domain>/CLAUDE.md` → `## Shared
guardrails`, `## Outputs`). Блоки канонизируются там; если текст навыка
расходится с профилем — профиль контролирует.


## Примеры

- «Что говорил работник про 12 числа?» → цитаты каждого опроса по этой дате.
- «Где расхождения между показаниями A и B?» → ⇄-таблица.
- «Что нам нужно ещё собрать?' → sources.md pending + почему это важно.
- «Сильно ли противоречие в сумме недостачи?» → все упоминания суммы, кто,
  когда; оценка источника (акт инвентаризации vs. воспоминание).

## What this skill does not do

- Не добавляет данные (это investigation-add).
- Не пишет memo (это investigation-memo); но может подсветить, что лог
  уже достаточен для memo.
