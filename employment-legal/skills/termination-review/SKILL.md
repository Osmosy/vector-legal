# /termination-review — ревизия увольнения по ТК РФ

   матрица полномочий.

4. Любой флаг сработал → эскалация по таблице до, а не после.

## Purpose

Большинство увольнений проходят нормально. Немногие становятся исками.
Этот навык ловит вторые до подписания приказа.

## 🔴 Главный флаг ТК РФ: ат-вилл не существует

В РФ **нет увольнения без основания из закрытого перечня** (ст. 77–83 ТК).
«Просто расстаёмся», «не прошёл по культурному фиту», «уходит по-тихому за
severance» — не работают как механизм увольнения по инициативе
работодателя. Нарушение порядка или отсутствие основания → восстановление
(ст. 394 ТК), оплата вынужденного прогула (по среднему заработку — ст. 394
ч. 2), компенсация морального вреда, судебные расходы, плюс штраф по
ст. 5.27 КоАП (ч. 4: 10–100 тыс. руб. юрлицу; повторно — до 70 тыс. по
ч. 5 `[модельные знания — verify]`). В каждом memo: если предлагаемое
основание — не из ст. 77–83, это 🔴 до остального анализа.

## Workflow

### Шаг 1: Базовые факты

- Сотрудник: должность, стаж, отдел
- Планируемое основание: **одно из ст. 77–83, не «конфликт с руководителем»**
- Кто инициатор: работодатель (ст. 81) / соглашение (ст. 78) / работник
  (ст. 80) / независящие (ст. 83)
- Категория: беременная? ребёнок до 3 лет? одинокий родитель до 14/18-инв.?
  несовершеннолетний? член профсоюза? в отпуске/на больничном?
- Планируемая дата увольнения
- Что уже сделано (уведомления, акты, объяснения)

### Шаг 2: Выбор и проверка основания (закрытый перечень)

**Карта ст. 77** (по ч. 1):

| Пункт | Основание | Ключевые риски |
|---|---|---|
| ч. 1 п. 1 | Соглашение сторон (ст. 78) | Отмена односторонне невозможна; давление = оспаривание |
| ч. 1 п. 2 | Истечение срока договора (ст. 59) | Забыли уведомить за 3 дня — договор становится бессрочным |
| ч. 1 п. 3 | Собственное желание (ст. 80) | Принуждение = отмена; забрать заявление можно в течение всего срока |
| ч. 1 п. 1 ч. 1 ст. 81 | Ликвидация/ИП закрыт | Уведомление 2 мес. + СФР/центр занятости; пособие 100% среднего |
| ч. 1 п. 2 ч. 1 ст. 81 | Сокращение штата/численности | Полная процедура ниже |
| ч. 1 п. 3 ч. 1 ст. 81 | Несоответствие должности по мед. результатам | Из медорганизации, предложение вакансий, увольнение — только если нельзя перевести |
| ч. 1 п. 4 ч. 1 ст. 81 | Смена собственника (руководитель, зам, ГБ) | Только эти категории |
| ч. 1 п. 5 ч. 1 ст. 81 | Неоднократное неисполнение, есть взыскание | Взыскание должно быть непогашенным, дисциплинарка по ст. 193 |
| ч. 1 п. 6 ч. 1 ст. 81 | Разовое грубое нарушение | Прогул, пьянство, разглашение, хищение, нарушение охраны труда |
| ч. 1 п. 7 ч. 1 ст. 81 | Виновные действия лица, обслуживающего ценности | Только работы из ПЕРЕЧНЯ Постановления Минтруда №85 |
| ч. 1 п. 7.1 ч. 1 ст. 81 | Утрата доверия к лицу, обслуживающему ценности | То же ограничение категории |
| ч. 1 п. 8 | Аморальный поступок воспитателя | Только для педагогов |
| ч. 1 п. 9/10 | Решение/действия руководителя с тяжкими последствиями | Только руководитель/зам/ГБ |
| ч. 1 п. 13 | Дополнительные основания для руководителя | Уставом организации |
| ст. 81 ч. 1 п. 14 | Отдельные основании для др. категорий | Отдельные федеральные законы |
| ст. 83 | Независящие от воли сторон (призыв, лишение допуска, дисквалификация, смерть) | Основание фиксируется документом |
| ст. 71 | Не прошёл испытание | Предупреждение за 3 дня, причины, не в период больничного/отпуска |

**Если пользовательское основание не маппится — 🔴 stop.** Спросить: «Какое
основание из ст. 77–83 вы имеете в виду?» Не «додумывать» основание.

### Шаг 3: High-risk флаги

| Флаг | Почему | Проверить |
|---|---|---|
| **Защищённая категория** | Ст. 261: беременные, дети до 3 лет, одинокие родители до 14 (18-инвалиды) | Только ликвидация; срочный договор беременной продлевается (ч. 2 ст. 261) |
| **В отпуске/на больничном** | Ч. 6 ст. 81: нельзя в период временной нетрудоспособности и в отпуске | Дата увольнения не в отпуске/больничном по инициативе работодателя |
| **Свежая жалоба** | Реталиация: жалоба в ГИТ, прокуратуру, иск | Хронология жалоба → решение об увольнении < 3 мес. — флаг `[review]` |
| **Возражение по зарплате** | Ст. 142: при задержке зарплаты работник может отсутствовать; увольнение в это время = реталиация | Задолженность работодателя перед этим сотрудником |
| **Инвалидность/мед. ограничения** | Предложение вакансий обязательно (ч. 3 ст. 81), квоты | ИПРА, медзаключение |
| **Профсоюз** | Ст. 373: мотивированное мнение; ст. 374 — увольнение профактивных | Членство в профсоюзе, мнение запрошено? |
| **Тонкая документация** | Для «неоднократного неисполнения» (п. 5) нужен непогашенный взыскание + документация | Есть взыскания? Какие? Не оспорены ли? |
| **Компаратор** | Дискриминация: кто-то ещё с тем же поведением не уволен | Кто ещё «нарушал» и не уволен |
| **Смена основания во время процедуры** | Ст. 53 ГПК `[verify]`: суды проверяют только законность фактического основания | Изменили основание после начала процедуры — риск |
| **Мобилизация/отпуск по уходу** | Отдельные гарантии | Проверить статус |

Любой сработавший флаг → эскалация по матрице. Категории ст. 261 + ст. 81
(кроме ликвидации) = ⛔ **НЕ ВОЗМОЖНО** — сообщить сразу.

### Шаг 4: Процедуры по основаниям (главный раздел)

#### Сокращение численности или штата (ч. 1 п. 2 ст. 81)

Чеклист (порядок нарушен = риск восстановления):

- [ ] **Приказ** о сокращении с датами и составом (не приказ об увольнении)
- [ ] **Уведомление каждого лично под подпись за 2 мес.** (ст. 180 ч. 2);
  при отказе — акт об отказе. Уведомление **центра занятости**: за 2 мес.
  (массовое сокращение — за 3 мес., см. критерии Постановления
  Правительства №99 `[model knowledge — verify]`); профсоюз — 2 мес.
- [ ] **Преимущественное право (ст. 179):** при равной производительности —
  семейные с иждивенцами ≥2, единственный кормилец, увечья/профболезнь,
  инвалиды ВОВ/боевых действий, повышение квалификации без отрыва.
  **Коллегиальный орган/комиссия** фиксирует сравнение — не решение
  руководителя единолично. Сравнивать только по должностям из «одного
  решения» (смежные позиции той же функции).
- [ ] **Предложение вакансий** (ч. 3 ст. 81 + ст. 180 ч. 3): **все
  соответствующие вакансии в данной местности** (и вышестоящие, если
  квалификация позволяет); под подпись; при отказе — акт. Вакансии
  предлагать **в течение всего срока предупреждения**, не один раз
  (практика ВС `[model knowledge — verify]`).
- [ ] **Согласие на досрочное сокращение** (ст. 180 ч. 5) — с сохранением
  части пособия. Если предлагали — зафиксировать отказ.
- [ ] **Профсоюз:** мотивированное мнение в 7 рабочих дней (ст. 372 —
  для ЛНА; ст. 373 — при увольнении членов), при несогласии —
  консультации `[model knowledge — verify]`. Прочие категории (молодые
  специалисты, инвалиды-чернобыльцы) — госорганы.
- [ ] **Массовость:** критерии ПП №99 (численность за 90 дней) →
  дополнительное уведомление органов занятости.
- [ ] **Дата увольнения:** не в отпуске/больничном (ч. 6 ст. 81); при
  нетрудоспособности — сместить до выхода.
- [ ] **Выходное пособие:** средний месячный заработок за 1-й месяц +
  сохранение среднего на период трудоустройства до 2 мес. (с зачётом
  первого) — ст. 178; север — до 6 мес. `(verify)`; для районов Крайнего
  Севера `[model knowledge — verify]`. Отпускная компенсация + зарплата —
  полный расчёт в день увольнения (ст. 140).
- [ ] **Личные дела, трудовая книжка/СФР:** сведения о трудовой
  деятельности + справки о зарплате за 2 года (приказ Минтруда) — выдать в
  день увольнения.

**Риски, которые надо считать в memo:** восстановление (ст. 394) —
оплата вынужденного прогула по среднему; моральный вред; 5.27 КоАП; при
массовости — проверка ГИТ с высокой вероятностью.

#### Соглашение сторон (ч. 1 п. 1 ст. 77)

- **Только добровольно.** Давление (угроза уволить по статье) = оспаривание
  `[model knowledge — verify]`.
- **Одновременно оформить:** срок увольнения, сумму, порядок выплат
  (в т.ч. за отпуск ст. 127), выдачу документов, поведение сторон
  (рекомендации, рекомендации) — письменно, оба экземпляра.
- **Анат-вилл-подмена:** соглашение НЕ может содержать обязанность уйти
  «по чистой совести», отказ от права на обращение в суд по неясным
  основаниям — неустойка за обращение = ничтожно (ст. 9, 168 ГК —
  ухудшение положения, `[model knowledge — verify]`). Законодательство не
  знает «release» как в США; максимум — урегулирование конкретных сумм.
- Компенсация по соглашению — свободная сумма; облагается НДФЛ/взносами
  свыше 6-кратного среднего заработка (для севера — 9-кратного)
  `[model knowledge — verify]`.
- Отменить согласие односторонне нельзя (Анисимов ВС №4-КГ16-3
  `[model knowledge — verify]`); направление уведомления об отмене —
  огибание ст. 78 — риск.

#### Прогул (подп. «а» п. 6 ч. 1 ст. 81)

- Определение: отсутствие >4 часов подряд **на рабочем месте** (только
  место из трудового договора, не из ПВТР по ошибке), либо всю смену.
- **Акт об отсутствии** — в день обнаружения, минимум 2 подписи свидетелей.
  Последующие дни — новые акты.
- **Запрос объяснений** (ст. 193): письменный, под подпись. **2 рабочих
  дня** на предоставление — не 24 часа. Отказ от объяснения → акт ≥2
  свидетелей; отсутствие объяснения ≠ блокирующее (акт заменяет).
- **Приказ** с дисциплинаркой: не позднее 1 мес. со дня обнаружения
  (без учёта болезни/отпуска) и 6 мес. со дня совершения.
- **Категории, которых нельзя уволить по п. 6:** беременные (261), в
  отпуске/больничном (ч. 6 ст. 81), несовершеннолетние — только с
  согласия ГТИ и комиссии по делам несовершеннолетних (ст. 269), члены
  профсоюза — мнение (ст. 373).
- **Смягчающие и соразмерность** (ст. 192): тяжесть, обстоятельства,
  предшествующее поведение. Уважительная причина (форс-мажор, больной
  ребёнок без возможности предупредить суд решает) — вероятность
  восстановления при споре.
- **Табельный учёт:** отметить НН (неявка); при споре — доказательства
  наличия на работе.

#### Неоднократное неисполнение (п. 5 ч. 1 ст. 81)

- Взыскания должны быть непогашенными (год, ст. 194; досрочное снятие
  по просьбе/инициативе/ходатайству — ст. 194).
- Каждый факт неисполнения — документирован: акт, докладная, приказ о
  взыскании. «Устные замечания» не считаются.
- Соразмерность: проступок→взыскание (ст. 192).
- Процедура ст. 193 полностью (объяснение, сроки, акт при отказе).

#### Несоответствие по здоровью (ч. 1 п. 3 ст. 81)

- Только по заключению медицинской организации, работодатель оплачивает
  обязательный медосмотр.
- Предложение вакансий, соответствующих здоровью; уволить можно только
  если вакансий нет или работник отказался (ч. 2 ст. 72.1).

#### Разглашение охраняемой тайны (подп. «в» п. 6 ч. 1 ст. 81)

- Охраняемая законом тайна: **персональные данные** (152-ФЗ), КТ (ФЗ-98),
  профессиональные тайны (адвокатская, врачебная, банковская и т.д.).
- **Режим КТ должен быть введён фактически:** перечень сведений приказом,
  ознакомление под подпись, допуск — иначе увольнение по этому пункту не
  выдержит суд.
- Пропорциональность и действительность: разглашение должно быть
  установленным (акт, фиксация), не «подозрение».

### Шаг 5: Финальный расчёт и документы (ст. 140, 127, 84.1)

- [ ] Зарплата за отработанное время + компенсация **всех** неиспользованных
  отпусков (ст. 127, 140) — в день увольнения (не «в день зарплаты»)
- [ ] Компенсация за «сверхнормативный» отпуск при увольнении по
  соглашению/сокращению — отдельной суммой; при сокращении допускается
  замена отпуска компенсацией (ст. 127)
- [ ] Пособие по ст. 178 (сокращение/ликвидация) или по соглашению
- [ ] Трудовая книжка и/или СТД-Р в день увольнения; при отсутствии
  работника — уведомление о необходимости забрать/согласие на почту
- [ ] Справка о заработке за 2 года (СФР/пособия), СЗВ-СТАЖ, справка 2-НДФЛ
  `[model knowledge — verify]`
- [ ] При недопуске имущества / увольнении за прогул — запрет
  «отработать 2 недели» не применяется: ст. 80 — по собственному желанию
  работник отрабатывает 14 дней только по собственному заявлению
- [ ] Проверка «задержки трудовой книжки» — если не выдали в день
  увольнения, ст. 234 ТК (обязанность возместить не полученный заработок)

### Шаг 6: Documentation check

Для увольнений по «виновным» основаниям (п. 5–13):

- [ ] Бумажный след: акты, докладные, объяснения, приказы — в хронологии
- [ ] Хронология согласуется с приказом об увольнении
- [ ] Нет свежих документов, противоречащих основанию (премия за тот же
  период, благодарность)
- Вопрос «почему сейчас»: если человек «плох» год — что изменилось
  сейчас? Ответ зафиксирован.

## Consequential-action gate (увольнение живого человека)

Если Роль = не-юрист и пользователь просит финализировать приказ/уведомление:

> Увольнение — действие с юридическими последствиями (риски: восстановление
> через суд, оплата вынужденного прогула, моральный вред, штраф
> ст. 5.27 КоАП). Драфт прошёл ревизию юриста?
>
> Если нет — бриф юристу (1 стр.): сотрудник, основание, категория, что

## Decision tree

Закрыть по формату practice profile. Специфичные для увольнения опции:

1. **Подготовить пакет документов** — приказ, уведомление, акт, соглашение
   о расторжении (черновик)
2. **Эскалировать** — к [аппруверу] с флагом
3. **Дособрать факты** — акты, объяснения, вакансии, доказательства
4. **Наблюдать** — в трекер (если решено отложить решение)
5. **Другое**

## Что этот навык не делает

- Не решает, увольнять ли. Он проверяет решение.
- Не ведёт разговор с сотрудником.
- Не гарантирует отсутствие иска — снижает риск, ловя очевидное.
- Не считает зарплатные суммы (расчёт при увольнении) — см. wage-hour-qa;
  суммы из профилей/скриптов помечать `[verify — проверить расчёт]`.
