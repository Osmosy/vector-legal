# International Expansion Skill — приём иностранцев и найм за рубежом

## Matter context

По practice profile.

## Право РФ: статусы иностранных работников (ФЗ-115 `[model knowledge — verify]`, реквизиты статей проверить)

| Статус | Кто | Ключевые условия найма |
|---|---|---|
| **Без визы + патент** (ст. 13.3) | большинство безвизовых стран (Узбекистан, Таджикистан…) | патент с указанием региона и профессии; приём — только по региону патента; **уведомление МВД о договоре в 3 рабочих дня** (ст. 13 п. 8); взнос работодателя… нет — оплату патента делает работник; ДМС полис обязателен |
| **Виза + РП/разрешение на работу** (ст. 13.2/13.4) | визовые страны | работодатель сначала **разрешение на привлечение** + **разрешение на работу** сотруднику (квоты!); уведомление МВД в 3 раб. дня |
| **ЕАЭС** (Армения, Беларусь, Казахстан, Кыргызстан) | договор ЕАЭС | без патента/разрешений; уведомление МВД в 3 раб. дня всё равно обязательно |
| **ВКС** (ст. 13.2) | высококвалифицированные специалисты — зарплата ≥ 750 тыс. руб./год... порог уточнить ежегодно `[model knowledge — verify]` — с 2023 г. 750 тыс. с 2025 и исключения | разрешение ВКС на работодателя + работнику; уведомления МВД (приём/увольнение/отпуск >1 мес./зарплата < порога) |
| **РВП/ВНЖ** | проживающие в РФ | работают без патента/разрешений; ВНЖ — по всей РФ; РВП — только по региону РВП |
| **Студенты-очники** | на законном основании | работают без патента при очной форме (ст. 13 ч. 4 пп. 7 `[verify]`) |
| **Граждане ЕАЭС-«белые»** | — | равные трудовые права с РФ (рассматривать как обычных работников ТК) |

**Уведомление МВД (ст. 13 п. 8 ФЗ-115):** о заключении и расторжении
трудового/ГПХ договора с каждым иностранным работником — **3 рабочих
дня**; форма — приказ МВД `[model knowledge — verify]`; нарушений сроков —
штраф ст. 18.15 КоАП (юрлицам 400 тыс.–1 млн руб. за нарушение порядка
привлечения; за каждого работника может считаться отдельным
правонарушением `[review]`).

**Запреты:** работать иностранному работнику разрешено только по
профессии из патента/разрешения и в регионе; перевод в другой регион —
новый патент/разрешение `[model knowledge — verify]`.

**ГПХ с иностранцем:** тоже требует патента/разрешения и тоже
уведомляется МВД (договор ГПХ с иностранным физлицом — тот же порядок
уведомления). Переквалификация ГПХ→трудовой у иностранца добавляет
нарушение режима работы по патенту → cross-check `worker-classification`.

## Найм за рубежом (филиал/релокация)

| Модель | Что это | Когда |
|---|---|---|
| **Аккредитованный провайдер труда** (аналог EOR: Global PEO) | третье юрлицо — официальный работодатель | 1–5 человек, страна без сущности; проверка: аккредитация в реестре local-регулятора, кто несёт ответственность за ТК-гарантии |
| **Собственное юрлицо** | регистрация + местный трудовой договор | >5–10 чел., долгосрочная стратегия |
| **Подряд с местной компанией** | услуги, не найм | если контроль режима работы минимален — иначе риск переквалификации по местному праву |
| **Филиал/представительство** | без образования юрлица, но аккредитация | представительство не ведёт коммерческой деятельности `[model knowledge — verify]` |

**RF-специфика обратного направления** (российская компания отправляет
работника за границу/на удалёнку): командировка (ст. 166) vs. перевод к
другому работодателю vs. договор с зарубежной структурой; зарплатные
валютные ограничения и санкционные риски платежей `[review]` → эскалация.

## Cross-functional triggers (что спросить у смежных функций)

| Функция | Вопросы |
|---|---|
| **Бухгалтерия/налоги** | НДФЛ-статус (резидент/нерезидент), ставки, валютный контроль платежей, взносы на ВКС (фикс 7,6% на ОМС… проверить `[model knowledge — verify]`) |
| **HR** | локализация документов, знание русского (патент — сертификация `[verify]`), мед. справки, ДМС |
| **Безопасность/ИТ** | доступ к системам, экспортный контроль, ГОЗ-ограничения для иностранцев `[model knowledge — verify]` |
| **Приглашающая сторона** | кто подписывает приглашения на визу, несёт ли расходы, гарантийные письма |

## Трекер расширения (структура для expansion-kickoff/update)

Состояние держится в
`~/.hermes/legal/employment-legal/expansion-<country>.yaml`:

```yaml
country: Беларусь
mode: direct                 # direct / provider / entity / branch
opened: 2026-08-10
workers_planned: 3
checklist:
  - id: status-model
    item: "Выбрать правовую модель найма"
    owner: юрист
    status: done
  - id: payroll-provider
    item: "Проверить провайдера payroll/бухгалтерии"
    owner: финдир
    status: open
  - id: contract-template
    item: "Шаблон трудового договора по местному праву"
    owner: местный юрист
    status: open
    blocked_by: payroll-provider
updated: 2026-08-24
```

Обязательные элементы чеклиста (RU-приём иностранцев): правовая модель →
статус каждого кандидата → разрешения до подачи оффера → уведомления МВД
→ ДМС/медосмотр → ПДн (трансграничная передача!) → интеграция в leave-трекер.

## Guardrails

- **Пороги и формы уведомлений — верифицировать каждый раз** (web_search +
  `[pravo.gov.ru — verify]`): размер зарплатного порога ВКС, формы МВД,
  размер госпошлин меняются.
- Санкционные и контрсанкционные ограничения (указы Президента о запрете
  отдельным категориям найма)`[review]` — проверять при каждом новом
  гражданстве.
- Двойное юрисдикционное попадание (работник в РФ remote на инофирму и
  наоборот) — риски ПДн (трансграничка), валютного контроля — всегда
  эскалация.

## Что этот навык не делает

- Не подбирает страну-модель — только структурирует решение.
- Не проверяет аккредитацию провайдеров сам — даёт чеклист проверки.
