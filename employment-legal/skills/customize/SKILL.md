# /customize

Направленная правка `~/.hermes/legal/employment-legal/CLAUDE.md` без
полного cold-start. Один запрос — одна секция; перезапись файла только по
изменённой секции.

## Маппинг запросов на секции

| Пользователь говорит… | Секция профиля |
|---|---|
| «кто что подписывает», «матрица», «полномочия» | `## Матрица полномочий HR/юрист/директор` |
| «эскалации», «кому слать», «канал» | `## Эскалации`, автоэскалации |
| «ЛНА», «ПВТР», «положение» | `## Организация по ТК РФ` → таблица ЛНА |
| «категории», «беременные», «профсоюз» | категории с ограничениями (ст. 261, ч. 6 ст. 81) |
| «ГПХ», «подрядчики», «фискальный риск» | доля ГПХ, пороги ГПХ-договоров |
| «tone», «тон», «куда пишем» | `## House style` |
| «header», «пометка», «конфиденциально» | `## Выходные документы` (аккуратно: канонические блоки менять не надо) |
| «штат», «численность» | `## Организация по ТК РФ` → Штат |
| «1С», «СБИС», «HRIS», «отпуска в системе» | `## Системы` |
| «иностранцы», «ВКС», «патент» | `## Приём иностранцев` |
| «приказы», «шаблон договора», «seed» | `## Seed documents` |

## Инструкции

1. Прочитать профиль целиком. Найди запрошенную секцию и точную строку.
2. Показать планируемый diff строкой: «Было: [X]. Стало: [Y]. Так?»
3. Подтверждение получить. Применить правку, перезаписав файл целиком
   (сохранить всё остальное байт-в-байт).
4. Если правка затрагивает то, что skills читают по имени секции, —
   проверить, что имя секции не изменилось.
5. Подтвердить: «Обновил [секция] в профиле».

## Guardrails

- **Не удалять канонические блоки** (header-правила, reviewer note, теги
  источников, decision tree, destination check) — на них опираются все
  навыки.
- **Проверять user-stated юридические факты:** если пользователь говорит
  «испытательный до 9 месяцев» — ст. 70 ТК говорит максимум 6 (руководители)
  / 3 (общий случай); поверхность расхождение до записи:
  «Вы сказали 9; по ст. 70 максимум 6 — что пишем?» `[проверить]`
- **Никогда не записывать персональные данные работников** (ФИО конкретных
  людей с их состоянием) — только роли, правила, категории.
- Если правка противоречит существующей секции (например «юрист не
  согласовывает ЛНА» при секции «юрист: обязательное») — показать конфликт
  и переспросить.

## What this skill does not do

- Не переинтервьюирует — для этого `cold-start-interview --redo`.
- Не меняет форматные каноны плагина.
