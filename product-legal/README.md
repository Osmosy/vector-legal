# Product Counsel — Продуктовый юрист (Vector Legal)

Адаптация [claude-for-legal/product-legal](https://github.com/anthropics/claude-for-legal)
(Anthropic, Apache-2.0) под российское право и Hermes Agent.

## Что это

Product-legal — практика, где юр ближе всего к бизнесу: launch review, ревизия
рекламы, оценка риска фичи, быстрые ответы «это проблема?». Работает на
**risk-калибровке, выученной из реальной истории запусков компании** — что
блокирует *у вас*, а не «в среднем по отрасли».

Выход — memo, документ или ответка в чат, которые юрист проходит за один
проход. Каждый выход — черновик для проверки юристом с указанием источников.

## ⚠️ Юридический дисклеймер (канонический)

**Всё, что производит плагин, — черновик для проверки юристом.** Не юридическая
консультация, не правовое заключение, не замена юриста. Нормы РФ цитируются
с тегами происхождения; «стабильные» статьи меняются (152-ФЗ и ФЗ-38
дорабатывались ежегодно с 2021 г.). Каждый документ требует проверки
квалифицированным специалистом.

## Структура

```
product-legal/
├── CLAUDE.md                      # Шаблон practice profile (заполняет cold-start)
├── README.md                      # Этот файл
└── skills/
    ├── cold-start-interview/      # Интервью + история запусков → risk calibration
    ├── customize/                 # Точечная правка профиля
    ├── matter-workspace/          # Рабочие пространства дел (для firm/мультиклиент)
    ├── launch-review/             # Запуск продукта: 9 категорий РФ + сектор-оверлеи
    ├── marketing-claims-review/   # Реклама: ФЗ-38 ст. 5, обязательные дисклеймеры, ЕРИР
    ├── feature-risk-assessment/   # Глубокая оценка одной фичи (ПДн/платежи/ИИ/контент)
    ├── is-this-a-problem/         # Быстрая триаж-ответка для Slack/Telegram
    ├── privacy-policy-ru/         # Политика обработки ПДн (152-ФЗ, приказ РКН №179)
    └── terms-of-service-ru/       # Оферта/пользовательское соглашение (ГК, ЗоЗПП)
```

## Быстрый старт

```
cold-start-interview          # 2 мин quick / 15 мин full — пишет профиля + калибровку
is-this-a-problem "<вопрос>"  # Отвечает за минуту по калибровке
launch-review <PRD|таск>      # Полный ревью запуска по фреймворку
```

До cold-start все навыки работают в **provisional mode**: generic дефолты
(право РФ, средний риск-аппетит) с меткой `[PROVISIONAL]`.

## Practice profile

Конфигурация живёт в `~/.hermes/legal/product-legal/CLAUDE.md` (в Claude-версии —
`~/.claude/plugins/config/claude-for-legal/product-legal/CLAUDE.md`; здесь путь
Hermes-нативный). Шаблон — `CLAUDE.md` в корне плагина. Профиль содержит:

- **Продукты компании** — что именно продаём: ПО/SaaS, товар (физический),
  телематические услуги, контент, фин-сервисы; кто пользователи (B2C/B2B);
  **каналы** — RU-рынок и/или экспорт (экспорт добавляет GDPR и местные режимы)
- **Risk calibration по истории запусков** — таблица «паттерн → что это значит
  здесь»: обычно FYI / требует работы / блокирует, с тайм-лайнами. Строится из
  10 прошлых launch review, не с потолка
- **Review framework** — 9 категорий РФ (см. skills/launch-review)
- **Матрица эскалаций** с порогами и автоматическими эскалациями
- **Marketing claims policy** — позиция по сравнительной рекламе, порог
  доказательств для «лучший/№1», история отклонённых заявлений
- **House style**, интеграции (трекер, хранилище, Telegram-канал)

### Право Российской Федерации (базовые замены против US-версии)

| CFL (US) | Vector Legal (RU) |
|---|---|
| FTC Act § 5 (deception/unfairness) | ФЗ-38 «О рекламе»: ст. 5 ч. 1 п. 1 (недобросовестная, некорректные сравнения), ч. 3 (недостоверная); штрафы ст. 14.3 КоАП + практика ФАС «Честный знак» по инфопродуктам |
| Endorsement Guides / disclosure overlays | Обязательные предупреждения: лекарства/БАД (ст. 24 ФЗ-38), финансовые услуги (ст. 28), «реклама» на блогерах (спонсорский контент, ст. 9), маркировка любой интернет-рекламы: erid-токен + ЕРИР + отчётность через ОРД (ст. 18.1 ФЗ-38) |
| COPPA / state minors rules | Согласие родителей на ПДн ребёнка до 14 лет (ст. 9 ч. 4 152-ФЗ); возрастная маркировка ФЗ-436; отдельные платформенные правила |
| Privacy policy “we collect X” | Политика обработки ПДн — обязательный опубликованный документ (ст. 18.1 ч. 2 152-ФЗ), содержание по приказу РКН № 179 от 05.09.2013; локализация баз ПДн (ч. 5 ст. 18); уведомление РКН (ст. 22) |
| UDAAP / auto-renewal | ЗоЗПП: ст. 10 (информация), ст. 16 (ничтожные условия), ст. 26.2 (дистанционная продажа, отказ 7 дней / 3 мес.), ст. 32 (отказ от услуги); Роспотребнадзор + штрафы гл. 14 КоАП |
| TCPA / CAN-SPAM | Согласие на рассылки/звонки (ст. 18 152-ФЗ при продвижении товаров — письменная форма; «согласие на связь» по ст. 17 ФЗ-126 для телефонии) `[model knowledge — verify]` |
| Money transmission / payments | ФЗ-161 «О национальной платёжной системе» (приём платежей, НСПК, безопасность), ФЗ-115 (ПОД/ФТ), ФЗ-54 (ККТ/чеки); лицензии ЦБ для фин-сервисов |
| Platform policies (Apple/Google) | Платформенные правила сторов `[platform policy — verify]` + для телематики: лицензия Россвязь (ст. 29 ФЗ-126), требования ФСБ (СКЗИ), хранение данных (ст. 10.6 ФЗ-149, ст. 64 ФЗ-126) |
| AI: state laws / AIA | Рекомендательные системы: маркировка + возможность отключения (ст. 10.1–10.3 ФЗ-123, ГОСТ Р 59276-2020, постановление № 2392) `[model knowledge — verify]`; ЭПР (ФЗ-258) для беспилотников/дистанционной медицины; 152-ФЗ для обработки ПДн в моделях |
| Attorney work product | Адвокатская тайна (ст. 8 ФЗ-63) — только для адвокатов; для in-house — `КОНФИДЕНЦИАЛЬНО — ВНУТРЕННИЙ ПРАВОВОЙ АНАЛИЗ`; защита как КТ (ФЗ-98) при введённом режиме |
| CourtListener / Westlaw | pravo.gov.ru + КонсультантПлюс/Гарант (через web_search, готового MCP нет); kad.arbitr.ru для практики ФАС/судов + sudrf.ru |

Это замены каркаса; калибровка (что блокирует у вас) — только из интервью и
истории запусков (как в CFL: никаких дефолтов «с потолка»).

## Provisional mode

До заполнения профиля все ревизии работают с generic дефолтами право РФ:
средний риск-аппетит, категории фреймворка из первых принципов (152-ФЗ,
ФЗ-38, ЗоЗПП, ФЗ-161 — базовые пороги, а не ваши). Каждый выход помечается
`[PROVISIONAL — запусти cold-start-interview для калибровки]`.

## Отличия от CFL

1. Право РФ вместо US (таблица выше), юрисдикция в профиле — обязательное поле
2. Пути: `~/.hermes/legal/product-legal/` вместо `~/.claude/plugins/config/…`
3. Интеграции: Jira/Linear/Asana → YouTrack/Кайтен/Яндекс.Трекер (или файлы),
   Slack → Telegram через Hermes gateway
4. CourtListener → КонсультантПлюс/Гарант через web_search + пометка `[verify]`,
   практика — kad.arbitr.ru
5. Добавлено два навыка, которых нет в CFL: **privacy-policy-ru** (политика ПДн
   152-ФЗ) и **terms-of-service-ru** (оферта/ToS) — для русскоязычного рынка это
   документы, которые нужны почти каждому запуску
6. launch-review: 9 категорий (добавлены «Платежи и фин-отношения» и
   «ИИ/алгоритмы» как отдельные) + RF-сектор-оверлеи
7. Два новых навыка закрывают типовой спрос RU-рынка на пакет документов запуска

## Связь с экосистемой Vector

- **Vector Work → legal** (6 навыков) — повседневные задачи
- **commercial-legal** — договоры с контрагентами (продавец/покупатель)
- **privacy-legal** — 152-ФЗ глубокая практика, оценки и инциденты ПДн
- **product-legal** (этот) — юр сторона запуска продуктов и рекламы
- **ai-governance-legal** — реестр use-case'ов ИИ, AIA; product-legal
  эскалирует туда при детекции ИИ-компонента
