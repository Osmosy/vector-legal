# /infringement-triage — триаж нарушений ИС

## Instructions

1. Прочитать профиль (постур enforcement, эскалации)
2. Определить сторону (наши права нарушают / мы нарушаем чьи-то) и режим
3. Ветку по типу права

## Trademark mode (товарные знаки)

### Сходство до степени смешения

Факторы (ст. 1477-1515 ГК + практика СИПН):

- Фонетическое сходство (звучание, ритм)
- Семантическое (значение, ассоциации)
- Визуальное (графика, шрифт, цвет)
- Однородность товаров/услуг (классы МКТУ + фактические потребительские
  круги — СИПН выходит за классы)
- Известность старшего знака

### Dilution (размывание)

Для известных знаков — ст. 1483 п. 2 (нельзя использовать известные
обозначения); защита известных знаков шире однородности. Признание
«общеизвестным» — через Роспатент.

### Недобросовестная реклама / сравнение

Использование чужого знака в сравнительной рекламе — ФЗ-38 «О рекламе»
ст. 5 (некорректные сравнения) + ГК. Отдельная оценка.

## Copyright mode

### Ownership

Кто автор и правообладатель? Служебное произведение (ст. 1295 ГК) —
если создано работником, права работодателю в определённых пределах —
проверить трудовой договор и служебные акты. Для вендоров, подрядчиков
и фрилансеров — договор отчуждения/лицензия (ст. 1288, 1234).

### Registration

В РФ авторские права **не требуют регистрации** — возникают в силу
создания (ст. 1259). Добровольное депонирование (ФИПС, РАО) —
доказательство, не право. Отсутствие регистрации — НЕ препятствие
защите (важно: не спрашивать «зарегистрировано ли» как обязательный
элемент).

### Access + substantial similarity

Комбинация: нарушитель имел доступ + работы сходны существенно
(инверсия доктрины: с доказательствами независимого создания — сильная
позиция).

### Исключения (аналог fair use — закрытый перечень ГК)

ГК ст. 1274 (цитирование в научных/полемических/критических/информационных
целях с указанием автора и источника; и иллюстрации в объёме, оправданном
целью), ст. 1275 (библиотеки, архивы), ст. 1264 (официальные документы —
не охраняются), ст. 1259 п. 5 (идеи, концепции, методы не охраняются),
ст. 1278 (публичное исполнение в местах открытого доступа), ст. 1280
(лицензионные экземпляры). **Перечень закрытый — не изобретать случаи;
fair use общего вида (трёхфакторный тест США) в РФ нет.** Проверять
конкретную норму и её границы.

### Safe harbor / ответственность информационных посредников

Ст. 1253.1 ГК: хостинг-провайдер, соцсеть, поисковик освобождаются от
ответственности при (a) не знал и не должен был знать, (b) при получении
уведомления — принял необходимые меры. Это основа для takedown-потока
(см. отдельный тakedown-скилл). Для хостинга нашего контента — не
виновник, но обязан реагировать на нотис.
### Output (АП-ветка)

Мемо с ownership/доступом/сходством/исключениями; опции (takedown,
cease-desist, компенсация 10К-5М ст. 1301, убытки).

## Patent mode (изобретения, ПМ, пром. образцы)

### Design (промышленный образец) — ветка сразу

Определить, речь ли о внешнем виде: если да — сравнение по
существенным признакам дизайна (таблица признаков + визуальное сходство;
«информированный потребитель» — ст. 1352). Если о функции —
utility-ветка.

### Utility-ветка

Состав патента (формула) ↔ продукт: **claim-chart как в fto-triage** —
после чего вердикт «похоже поп./не поп./нужен поверенный». Патентный
триаж без поверенного не завершается выводом.

## Выход

Общий триаж memo + Reviewer note (блок `⚠️ Reviewer note`: источники —
`[ФИПС][verify]` по реестровым объектам, `[kad.arbitr.ru][verify]`
по судебной практике, `[user provided]` для материалов; перед опорой —
сверить статус объекта по открытому реестру) + decision tree:
1. **Cease-desist** — драфт (мы обладаем правами)
2. **Ответ на претензию** — встречная позиция
3. **takedown** — для сетевого контента
4. **Оспорить** — возражение Роспатенту/СИПН
5. **Эскалировать** — по матрице
6. **Другое**

## Что этот навык не делает

Не делает вывод «нарушение есть/нет» — вероятностная оценка для юриста;
не заменяет поверенного в патентных вопросах; не подменяет полный
судебный анализ (до него — через cease-desist и поверенных).
