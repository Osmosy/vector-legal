## Shared guardrails (канон — practice profile)

No-silent-supplement / Currency trigger / Large input** — см.
practice profile (`~/.hermes/legal/<domain>/CLAUDE.md` → `## Shared

расходится с профилем — профиль контролирует.


## Important: deadline reference caveat

Дедлайны в реестре — **референсные, считанные из правил** (ГК ст.
1490-1515, 1430-1445; приказы Роспатента о пошлинах). Перед каждым
действием — сверка с реестром ФИПС `[ФИПС][verify]` или поверенным.
Автоматический платёж по дедлайну из этого реестра — никогда.

## Jurisdiction and type assumptions

| Тип | Срок действия РФ | Продление |
|---|---|---|
| Товарный знак | 10 лет с приоритета | бесконечные продления по 10 лет (ст. 1491 ГК) |
| Изобретение | 20 лет | (фарма — до 25; `[verify]`) |
| Полезная модель | 10 лет | не продлевается |
| Пром. образец | 5 лет, до 25 | продления по 5 лет |
| Программа ЭВМ / БД | вся жизнь автора +70 | не требуется |
| Ноу-хау | пока секрет | режим КТ |

Пошлины — по постановлению Правительства (размеры меняются) `[verify]`.

## The register

`~/.hermes/legal/ip-legal/portfolio.yaml`:

```yaml
assets:
  - id: TM-001
    type: trademark          # trademark | invention | utility | design | software | knowhow
    title: "[Знак]"
    number: "№000000"        # регистрация ФИПС — проверена [дата]
    classes: [35, 42]
    owner: "ООО Компания"
    status: active           # active | expired | pending | lapsed | cancelled
    priority_date: 2016-03-14
    expiry_date: 2026-03-14
    renewal_costs: "~[сумма] руб. [verify пошлины]"
    deadlines:
      - {date: 2026-03-14, type: renewal, lead_days: 180}
    notes: ""
```

## Режимы

### Режим 1: Inital (initialise)

**Источник:** (1) выгрузка из ФИПС/wipe, (2) перечисление от пользователя,
(3) существующий файл. Для каждого актива — заполнить поля, посчитать
дедлайны. Показать таблицу до записи; даты — с `[verify]` если не из
реестра.

### Режим 2: Report

```markdown
[TIER HEADER]

# IP Portfolio — отчёт [дата]

### Bottom line
[N объектов, M действий в течение 90 дней, самая срочная дата]

### ⏰ Действия в 90 дней
| ID | Объект | Действие | Дата | Статус | Оценка пошлины |
|---|---|---|---|---|---|

### 🔴 Просрочено / критично
| ... |

### 🟡 В горизонте года
[Список]

### Оценка портфеля
[По типам: N знаков, M патентов… Года истечения — дашборд]

### Дырки в охвате
[Классы без защиты, территория без регистрации (если есть
данные из профиля) — только то, что реально видно]
```

**Consequential-action gate:** оплата пошлины, подача заявления
продления — внешние действия; навык готовит черновик, не действует.

### Режим 3: Add

Спросить поля по одному или принять блоком. Валидация дат (expiry
отpriority + 10 лет для знака). Для реестровых РИД — предложит сверку с
ФИПС `[verify]` перед записью.

### Режим 4: Update

Изменение статуса/владельца/дейлайна. **Consequential gate:** смена
владельца (уступка по ст. 1234 ГК требует регистрации перехода в
Роспатенте!) — флагнуть: «Переход права по регистрируемым РИД действителен
с момента регистрации (ст. 1232 ГК) `[settled]`».

### Режим 5: Audit

Сверка реестра с фактическим использованием знаков (использование —
обязанность, иначе риск досрочного прекращения ст. 1486 ГК): по каждому
активному знаку — где используется (упаковка, сайт, ТЗ), квитирование
доказательств использования. Долг — если знак не используется 3 года,
другие могут оспорить `[settled — практика СИПН verify]`.

## Integration: ip-renewal-watcher agent

Если настроен внешний cron/agent — он проверяет портфель по cadence и
шлёт алерты в Telegram; здесь — только приём флагов. Без агента —
дайджест по запросу `portfolio report`.

## Close

Reviewer note (источники дат!) + decision tree: 1. Подготовить продление —
перечень для поверенного · 2. Внести пропущенные активы · 3. Эскалировать
критичные дедлайны · 4. Аудит · 5. Другое.

## Чего не делает

Не принимает пошлины и не подаёт документы — только реестр и напоминания;
не заменяет реестр ФИПС; для переходов прав — всегда ст. 1232
регистрация.
