## ЭТО ПЕРВЫЙ ПРОХОД, НЕ CLEARANCE OPINION

Навык даёт скрин для юриста/поверенного. Полный clearance включает поиск
по реестрам ФИПС с квалифицированной проверкой фонетических/семантических
совпадений, международные реестры и правовую оценку — это работа
поверенного. Формулировка в заголовке выхода всегда:
`«Первый проход — НЕ clearance opinion»`.

## Matter context / загрузка профиля

`~/.hermes/legal/ip-legal/CLAUDE.md` — портфель (наши знаки), постур,
классы МКТУ компании. Плейсхолдеры → `[PROVISIONAL]` (knockout по
абсолютным основаниям ст. 1483 ГК, честно: «поиск по ФИПС не выполнен»).

## Intake

> 1. **Знак:** слово/логотип/комбинированный? Точное написание?
> 2. **Классы МКТУ:** какие товары/услуги? (42 — софт, 35 — реклама,
>    29/30 — продукты и т.д.)
> 3. **География:** только РФ? Экспорт (Мадрид)? EU/США?
> 4. **Использование:** уже используете или планируете с даты?
> 5. Кто подаёт: сами или через поверенного?

## Knockout check — абсолютные основания (ст. 1483 ГК)

Быстрый скрин до поиска сходств:

- **Только описательные элементы** (ст. 1483 п. 2): обозначение, состоящее
  только из общих названий товара/услуги; несамостоятельные элементы
  («супермаркет» для супермаркета)
- **Некапабилити:** только географические названия, только фамилии
  исторических лиц
- **Ложь/введение в заблуждение:** заявляет о свойствах товара, которых нет
- **Официальные символы и знаки международной защиты** (флаги, эмблемы)
- **Моральные основания / общественные интересы**

Knockout не = провал: иногда достаточно добавить самостоятельный элемент.
Фиксировать вердикт с основанием `[ГК ст. 1483, пункт]` `[settled —
подтверждено YYYY-MM-DD]` при проверке.

## Similar marks check

### Что подключено

- **ФИПС открытые реестры:** для РФ — web_search / прямой поиск по
  fips.ru (реестр товарных знаков). Результаты — `[ФИПС][verify]` +
  номер регистрации обязателен. Если достать записи не удалось —
  честно сказать, не выдумывать
- **WIPO Global Brand DB** — для международных знаков `[verify]`
- **Ссылки из профиля на зарубежные реестры** — если есть

### Фоллбэк — нет доступа к базам

> Подключения к реестру нет: поиск по открытым данным ФИПС через
> web_search ограничен. Для надёжного Clearance нужно: (а) выгрузка
> ФИПС/запрос через поверенного, (б) коммерческая база, или (c)
> ручной поиск. Сейчас могу пройтись только по [что нашлось публично].
> `[PROVISIONAL — скрин не полный]`

### Для каждого найденного похожего знака

| Поле | Что фиксировать |

| Регистрация | № + правообладатель + даты |
| Классы МКТУ | Пересечение с нашими?! |

| Статус | Действует / прекращён / оспаривается |
| Источник | `[ФИПС][verify]` / `[WIPO][verify]` / `[web search — verify]` |

### Adjacent families sweep (обязателен перед выводом)

Проверить классы по соседству (35/42; 5/30 и т. п.), правообладателя
(не наши ли), наши старые регистрации.

## Risk factors смешения (ст. 1477-1515 ГК)

Ключевые факторы (ориентир для оценки СИПН-практики):

- **Сходство до степени смешения** — общий вывод по фонетике/семантике/
  визуалу совокупно
- **Однородность товаров/услуг** — классы и пересечение потребительских
  кругов; СИПН смотрит и смежные классы
- **Известность чужого знака** — «известный» знак защищается шире
- **Добросовестность**: наш знак описательный? их знак «лежит» и они
  не используют (ст. 1486 ГК — риск досрочного прекращения неиспользуемых)?

**В РФ не «likelihood of confusion» как формула US — есть своё понятие
сходства до степени смешения; не переносить тесты напрямую.**

## Recommended next steps

1. **Knockout пройден, похожих не найдено** → «подать заявк» через
   поверенного; скилл не подаёт
2. **Найдены похожие** → юрист: разбор совпадений, риск-оценка, опции
   (переименовать / сузить классы / оспорить их неиспользование
   по ст. 1486)
3. **Знак уже используется 3-й стороной** → `infringement-triage`
4. **Экспорт:** классы для Мадридской системы, национальные заявки —
   через поверенных target-стран

4. **Дособрать факты** — что осталось проверить
5. **Другое**

## Reviewer note

источники (номера регистраций — только при реальном `[ФИПС][verify]` в

повторная проверка реестра ФИПС перед подачей заявки или
инвестированием в бренд.
