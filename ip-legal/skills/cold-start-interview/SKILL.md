# /cold-start-interview — IP-практика

Первый запуск пишет `~/.hermes/legal/ip-legal/CLAUDE.md`; `--redo`
переинтервьюирует с показом diff. Это самый длинный из интервью плагина
(30+ вопросов), поэтому pacing-правила здесь строже всех: не больше 2–3
*отвечаемых промптов* в ход (подчасти считаются отдельно), тест — помещается
ли на один экран. «Скажи 'пауза'» — сохранение с `<!-- SETUP PAUSED AT: ... -->`
и `[PENDING]`-маркерами.

## Проверка фактов на лету

Когда юрист называет номер регистрации, класс МКТУ, дату, порог, юрисдикцию
— сантай-проверить до записи. Расхождение — «Вы сказали [X]; я понимаю [Y] —
что пишем? `[premise flagged — verify]`». Неверный факт в профиле
тиражируется во все будущие выходы.

## Fork-first preamble (3–4 строки, до любых вопросов)

> **`ip-legal` — для ИС-практики: товарные знаки, патенты, авторское право,
> секреты, OSS, промышленные образцы.** Не твоя область?
> `legal-builder-hub:related-skills-surfacer`.
>
> Quick start (3 мин): роль, практика-микс, юрисдикция, posture. Full (15 мин):
> эти плюс playbook-позиции, матрица одобрений C&D/DMCA, watch-список брендов,
> house style, seed-документы.
>
> Quick or full?

Дождаться выбора до остальных вопросов.

## Real-matter check (как в law-student)

Если запрос звучит как реальная ситуация (реальные имена, суммы, даты,
«наш поставщик скопировал логотип») — стоп. Консультация = квалифицированный
юр. специалист; навык — исследование и структура.

## Часть 0: Кто использует и что подключено

**Кто использует?** (кормит header работ)

1. **Юрист/юрспециалист** — full power, header `КОНФИДЕНЦИАЛЬНО — ...`
2. **Патентный поверенный (РФ)** — зарегистрирован в Роспатенте (ФЗ-316 ст. 22).
   На делах, «разумно необходимых и сопутствующих» ведению дел перед
   Роспатентом — коммуникации с клиентом защищены как профессиональная тайна
   поверенного (ст. 9 ФЗ-316); на вне-Роспатент-практике (товарные знаки,
   копирайт, OSS, договоры) защиты нет → честная пометка
   `КОНФИДЕНЦИАЛЬНО — НЕ PRIVILEGED — ПОКАЗАТЬ КУРАТОРУ`.
3. **Не-юрист с доступом к юристу** — фаундер, бренд-менеджер, OSS-офицер.
4. **Не-юрист без регулярного доступа** — сам справляешься.

Для 3–4 — одна вставка (не повторять на каждом выходе):

> Здесь работают все функции — исследование, ревизия, драфтинг, трекинг.
> Два отличия: (1) выходы — research для проверки юриста, не вердикты;
> (2) пауза перед шагами с правовыми последствиями (отправка C&D, filing
> takedown, регистрация, clearance-решение) — бриф для юриста прилагается.
> Несколько часов юриста в правильный момент дешевле ошибки.

Для 4 — путь к юристу: реестры адвокатских палат регионов, ФПА referral;
для ИС — патентные поверенные (Реестр Роспатента) и юр.клиники вузов.

**Микс практики — ветвящий вопрос (до всего остального):**

> Какие предметы ИС в работе? (все применимые)
>
> - **Товарные знаки** (clearance / подача / защита / бренд-мониторинг)
> - **Патенты** (заявки / споры / лицензирование)
> - **Промышленные образцы** (ГК ст. 1352)
> - **Авторское право** (clearance / лицензии / защита / ЗоИС)
> - **Секреты производства (ноу-хау)** (режим КТ ФЗ-98, misappropriation, exit-протоколы)
> - **OSS** (совместимость лицензий / политики)
> - **Селекционные достижения / топологии ИМС** (редко, но ГК ч. 4)

Ответ **жёстко ветвит остальное интервью**: trademark-only не получает вопросов
о патентных заявках; patent-only не получает brand-watch. Субфокусы записать
(«товарные знаки — clearance и защита, без prosecution») для прореживания
нижеследующих секций.

### Интеграции

Роспатент/ФИПС (открытые реестры — поиск с `[ФИПС][verify]`), web_search
(kad.arbitr — практика СИПН), Telegram для алертов. КонсультантПлюс ⚪.

## Часть 1: Объём практики

> Для каждого выбранного предмета: сколько объектов в год? (регистраций
> знаков / патентных заявок / споров / OSS-ревизий). Портфель — сколько
> активных знаков/патентов? (это feeds /portfolio)

## Часть 2: Юрисдикционный контур

> Где работаете?
>
> - **Товарные знаки:** РФ (Роспатент) / Мадридская система (МКДУ/МПИ) /
>   экспортные регионы. Парижский союз, Ниццкая классификация МКТУ.
> - **Патенты:** РФ (Роспатент, ФИПС-реестры) / ЕАПО / PCT.
> - **Споры:** СИПН (Суд по интеллектуальным правам) — специфика компетенции
>   ст. 16 ФЗ-«О СИПН»; Роспатент-палаты.
> - **Авторское право:** возникновение с момента создания (ст. 1259 ГК —
>   регистрация не требуется, но реестры РАО/ЕРН и депонирование используются
>   как доказательства)`[verify]`.

## Часть 2: Практика-документы

Только релевантные миксу:

> Пошлите (пути файлов): регламент реакции на нарушения (если есть),
> brand-guidelines, перечень watched-знаков, шаблоны лицензий, OSS-политика,
> позиция по компенсации (10 т — 5 млн, п. 3 ст. 1252 ГК — какой диапазон
> ваш), шаблон протокола разногласий по IP-пунктам.

## Часть 3: Enforcement posture (2–3 мин) — самое важное при trademark / бренд-защите

> При явном нарушении — подделка марки, скопированное изображение, слишком
> близкий продукт — где ваша практика? (это в /infringement-triage и
> /cease-desist — каждый triage и драфт прогоняется через постур)
>
> - **Агрессивный** — C&D рано, готовы подавать иск.
> - **Вымеренный** — сначала мягкое письмо или outreach, эскалация только
>   при игноре или реальном коммерческом ущербе.
> - **Консервативный** — assert только при вероятности иска и визе бизнеса.

Три уточнения в ваших словах: **когда C&D** (confusion-likely + коммерческий
вред? любое использование зарегистрированного знака? только когда
takedown не работает?); **когда мягкое письмо** (физлица? мелкие юзеры?
симпатичные контрагенты?); **когда сразу иск** (repeat-infringers, известная
готовность контрагента бороться, бегущий срок).

**Кто одобряет отправку?** (в /cease-desist и /takedown драфт уходит к
именованному аппруверу и ждёт визы): С&D, мягкое письмо, takedown, иск.
**Автоматические эскалации:** контрагент — текущий клиент/партнёр; крупнее
нас; спор про патент; вероятный паблисити.

> Ещё: **отправка C&D — начало боя.** Важнейшая настройка плагина. Драфт
> уходит аппруверу и ждёт визы.

Записать в `## Enforcement posture`.

## Часть 4: Эскалации (1–2 мин)

> Кто получает memo, а кто решает:
> - **Clearance-конфликт** (реальное попадание на поданную марку)?
> - **FTO-blocker** (патент, на который продукт похож)? — engineering?
>   product? юрист?
> - **OSS-copyleft** (GPL-семейство в дистрибутируемом продукте)? — удалить,
>   открыть код, переписать?
>
> Как эскалируют сегодня — Telegram, email, ticket, standing meeting?
> Реалистичный turnaround — same day, 24 ч, к концу недели?

## Часть 5 (опциональная, trademark-only): бренд-мониторинг

Скипнуть если не trademark. Watched-знаки, юрисдикции мониторинга, сервис
(CompuMark-аналог РФ — нет; web_search-подход), cadence.

## Часть 6 (авторское право): ЗоИС-контакт

Для RU-доменов: реестры ЕРН РАО/ВОИС, blocking-уведомления ФЗ-149
ст. 15.6, ФАС-реклама. Для экспорта: DMCA-агенты как контрагентов.

## Запись профиля

Структура — `CLAUDE.md` в корне плагина. Использовать слова юриста. После
записи: «Что я понял неправильно?», предложить тест: clearance/C&D
мини-пример, bulk-load портфеля при подключённых ресурсах.

## Provisional mode

Generic дефолты: РФ, средний постур, без playbook. Тег `[PROVISIONAL]`
в каждой находке. Список «одна вещь»-deal-breaker строится интервью —
без настройки нет «первой проверки».

## Scaffolding, not blinders

Чеклист интервью — floor, не ceiling. Всё в теме ИС — отвечать, с пометкой
дополнительного, где нужно.

## When to Use (trigger-класс)

Первый запуск плагина / «настрой», / «onboard», «настрой IP-плагин».
Не для разовых консультаций.
