# /customize — правка practice profile IP

## Когда запускается

Пользователь хочет изменить что-то в practice profile ИС — порог
претензии, разрешённые OSS-лицензии, контакт поверенного — без
перезапуска интервью.

## Что делать

1. **Прочитать конфиг** `~/.hermes/legal/ip-legal/CLAUDE.md`
   (и company-profile.md). Плейсхолдеры → «Сначала `cold-start-interview`».

2. **Показать карту правок:**
   - **Портфель (обзор)** — сводка по типам РИД (детальный реестр —
     `portfolio`)
   - **Патентный поверенный** — контакт, договор, что делегируем
   - **Jurisdiction** — РФ/экспорт, Мадрид/PCT
   - **Enforcement posture** — агрессивность, порог C&D, СИПН-постур,
     дедлайны реакции
   - **Эскалации** — матрица и автоматические триггеры
   - **OSS-политика** — разрешённые/запрещённые лицензии, процесс
   - **House style** — тон претензий, формат memo, алерты
   - **Интеграции / Matter workspaces**

3. **Процитировать текущее значение.**

4. **Спросить новое значение.** Одно за раз.

5. **Diff → confirm → write.**

6. Подтверждение + «затронет: [навыки]».

## Конвенции

- Одна правка за раз; цитировать до; подтверждать; логировать изменение
- Портфель-детали — не здесь: через `portfolio add/update` (реестр yaml)
- Изменение OSS-политики — спросить: пересчитать текущие зависимости?
  (предложить `oss-review` по существующему списку)
- Не править seed documents — только `--redo`

## Типовые правки

- «Порог претензии — от 200К ущерба» → в Enforcement posture; сказать,
  что cease-desist будет предлагать претензии только выше
- «AGPL теперь запрещён везде» → OSS-политика запрет; предложить
  проверку текущего стека
- «Повсеместный дедлайн реакции на претензию — 10 рабочих дней» →
  Enforcement + напоминание, что deadline triage в cease-desist
  берёт из профиля
- «Поверенный теперь Иванов/фирма X» → обновить контакт + что ему
  делегируем (заявки/споры/всё)
