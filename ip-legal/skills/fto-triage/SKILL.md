## ЭТО НЕ FREEDOM-TO-OPERATE OPINION

Полное FTO — это поиск по всем юрисдикциям всех живых патентов,
квалифицированный разбор claims, правовая оценка. Поверенный делает.
Навык — структурированный скрин, чтобы юрист знал, где риск.

### A note on willfulness

В РФ нет «willful infringement» с тройными убытками как в США, но
умышленность влияет на суд: пост-уведомление использование может
считаться обя­зательностью не действовать недобросовестно (ст. 10 ГК) и
влиять на компенсацию. Поэтому: этот скрин нужно задокументировать.
Сделанный скрин — защита от «мы не знали».

## Intake

> 1. **Что выпускаем/запускаем?** Продукт, техпроцесс, метод
> 2. **География продаж:** РФ? ЕАЭС? Экспорт (какие страны)?
> 3. **Срок:** когда старт?
> 4. **Что уже знаем:** патенты конкурентов? предупреждения?
> 5. **Бюджет/критичность:** насколько критичен продукт?

## Scope — utility patents only

FTO-скрин здесь по изобретениям и полезным моделям. Промышленные
образцы (design) — отдельная ветка `infringement-triage` (визуальное
сходство, не функция). Если пользователь просит «проверь дизайн» —
перенаправить на этот триаж.

## Search

### Что подключено

- **ФИПС открытые реестры:** web_search по ключевым словам + МПК-кодам;
  результаты `[ФИПС][verify]` c номером патента. Полного полнотекстового
  поиска нет — честно фиксировать покрытие
- **Espacenet (EPO)** — для международных, `[web search — verify]`
- **Google Patents** — как вторичный

### Fallback — нет баз

> Подключённого патентного поиска нет: скрин через открытые источники
> ФИПС/Espacenet неполон. Полный FTO требует профессионального поиска
> (поверенный или коммерческая база — Orbit/Lens). Сейчас сделаю:
> (a) скрин по открытым данным по ключевым словам, (б) claim-чарт по
> [патентам, которые вы назовёте], (в) план для поверенного.

### Supplementary signals (не заменяют поиск)

- Патентные споры конкурентов (kad.arbitr.ru, СИПН — `[verify]`)
- Профильные конференции/статьи конкурентов (тех. публикации, но это
  сигналы, не поиск)
- Патентные семейств конкурентов из их пресс-релизов

## Для каждого найденного патента

| Поле | Фиксировать |
|---|---|
| №, название | [ФИПС][verify] |
| Правообладатель | Компания/физлицо |
| Статус | Действующий/истёк/отменён (пошлины!) |
| МПК | Класс |
| Заявка/приоритет | Даты |
| Территория | РФ / ЕАПК / PCT-фаза |
| Источник | Тег |

## Claim-chart first pass

Для каждого патента — первичная таблица по независимому пункту:
«признак формулы ↔ элемент продукта» с честными колонками:

```markdown
### [Патент №] — независимый пункт 1
| Признак формулы | В нашем продукте |
|---|---|
| [признак 1] | [соответствует / отсутствует / неясно] |
| ... | ... |
[Вердикт первого прохода: похоже поп./не поп./нужен поверенный]
```

Все вердикты — предварительные; «неясно» лучше фальшивой уверенности.

## Risk ranking

- 🔴 **Высокий** — действующий патент конкурента, claim-chart почти
  совпадает, продукт критичен → поверенный до запуска
- 🟠 **Средний** — патент в смежной области, «неясно» в claim-chart,
  или патент истекает скоро → поверенный + план Б (обход)
- 🟡 **Низкий** — патент истёк/исключён, признак отсутствует →
  документировать и жить
- ⚪ **Не покрывает** — территория/статус не в релевантной зоне →
  записать (для аудиторского следа)

## Open questions

Что осталось непонятным: формулировки формулы, статус, объём семейства.
Не выдумывать.

## Recommended next steps

1. Поверенный по 🔴 патентам — полный разбор
2. Обходные решения — инженерные альтернативы (обход признака)
3. Договорная защита — лицензия у правообладателя ст. 1235
4. Оспаривание — возражение против выдачи (СИПН, если патент мешает)
5. Документы для запуска — фиксация скрина как due diligence

## Non-lawyer gate

Если Роль = не-юрист: «Это скрин, не FTO-мнение. Существующая судебная
практика по компенсациям до 5 млн руб. по ст. 1252 ГК и риск запрета
деятельности — не запускать продукт по такому скрину без юриста и
поверенного.»

## Reviewer note

Каждый выход — с блоком `⚠️ Reviewer note` по формату practice profile:
источники (номера патентов — только при реальной проверке
`[ФИПС][verify]` в этой сессии; патенты от пользователя —
`[user provided]`), покрытие (какие базы/МПК проскринированы — честно),
флаги, перед опорой на вывод — профессиональный патентный поиск
поверенным перед запуском продукта.
