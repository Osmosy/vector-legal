# IP Counsel — интеллектуальная собственность (Vector Legal)

Адаптация [claude-for-legal/ip-legal](https://github.com/anthropics/claude-for-legal)
(Anthropic, Apache-2.0) под право РФ (ГК РФ ч. 4) и Hermes Agent.

## Что это

Первая линия по ИС для in-house: быстрый clearance знака до подачи,
триаж входящих претензий, C&D и takedown, FTO-скрин перед запуском
продукта, intake изобретений, revизия IP-пунктов договоров, OSS-ревизия
зависимостей, портфель с дедлайнами. Всё — first pass для проверки
патентным поверенным; не замена поверенного.

## ⚠️ Юридический дисклеймер (канонический)

**Всё, что производит плагин, — черновик для проверки юристом/патентным
поверенным.** Не юридическая консультация, не «clearance opinion», не
«patentability opinion». Поиск по реестрам требует проверки по первичным
реестрам ФИПС. Источники указываются явно.

## Структура

```
ip-legal/
├── CLAUDE.md     # Шаблон practice profile (заполняет cold-start)
├── README.md              # Этот файл
└── skills/
    ├── cold-start-interview/  # Интервью → practice profile
    ├── customize/             # Точечная правка профиля
    ├── matter-workspace/      # Рабочие пространства дел (firm)
    ├── clearance/             # Первая проверка товарного знака (ФИПС)
    ├── cease-desist/          # Претензия по ИС: отправка и приём
    ├── takedown/              # Триаж и подготовка takedown/жалоб
    ├── fto-triage/            # Freedom-to-operate скрин (патенты)
    ├── infringement-triage/   # Триаж claims о нарушении (ТЗ/авторские/патенты)
    ├── invention-intake/      # Intake изобретений, скрин патентоспособности
    ├── ip-clause-review/      # Ревизия IP-пунктов договоров
    ├── oss-review/            # OSS-ревизия: лицензии зависимостей
    └── portfolio/             # Портфель ИС: регистрация, дедлайны
```

## Быстрый старт

```
cold-start-interview       # практика, юрисдикция, реестры
clearance <знак>           # первый проход по товарному знаку
oss-review <package.json>  # лицензии зависимостей
portfolio list             # портфель и дедлайны
```

## Practice profile

Конфигурация живёт в `~/.hermes/legal/ip-legal/CLAUDE.md` (шаблон —
`CLAUDE.md`). Профиль: портфель (знаки/патенты/ПО), форс
подачи через поверенных, эскалации и СИПН-постур, OSS-политика.

### Право РФ и источники (замены против US-версии)

| CFL (US) | Vector Legal (RU) |
|---|---|
| USPTO TESS / trademark search | **ФИПС / Роспатент** открытые реестры (fips.ru — реестры ТЗ, изобретений, ПМ, промышленных образцов, программ) + web_search `[verify]`; для международных — WIPO Global Brand Database [verify] |
| TTAB / US courts | **СИПН** — Суд по интеллектуальным правам (споры: оспаривание решений Роспатента, нарушение прав; kad.arbitr.ru не ведёт СИПН-кейсы — свои источники) |
| DMCA §512 takedown | ГК ст. 1252 (требования о нарушении исключительных прав), ст. 1253.1 (ответственность информационных посредников — «уведомление о нарушении» для сайтов/хостингов); Роскомнадзор реестр запрещённых сайтов |
| USPTO patent prosecution | Роспатент: заявочная процедура (заявка, экспертиза по существу, ПМ и изобретения); ФИПС — формы, пошлины; Мадрид/PCT для экспорта |
| US copyright fair use | ГК ст. 1274 + исключения; свобода панорамы и др.; «fair use»-аналога нет — конкретные случаи по перечню |
| Patents/Trade secrets | ГК ст. 1350+ (изобретения, ПМ, промышленные образцы), режим коммерческой тайны (ФЗ-98) для ноу-хау (ст. 1465+) |
| US license law | **ГК ст. 1235-1254**: лицензионный договор, исключительная/простая лицензия, право использования; уступка — договор об отчуждении (ст. 1234); залог ИС (ст. 358.18+) |
| OSS licenses | Те же MIT/Apache/BSD (мировые лицензии) + РФ-специфика: распоряжение исключительным правом по ГК; AGPL/copyleft-вирусность для SaaS; copyleft-стеки в продуктах |

**Ключевые статьи ГК ч. 4** (сквозные): ст. 1225 (перечень объектов ИС),
ст. 1229 (исключительное право), ст. 1250-1254 (защита), ст. 1477-1515
(товарные знаки), ст. 1350-1407 (изобретения/ПМ/промышленные образцы),
ст. 1259-1302 (авторские права), ст. 1357+ (право на изобретение —
трудовые отношения с авторами, служебные произведения ст. 1295).

## Provisional mode

До cold-start: generic дефолты (право РФ, консервативный постур) с меткой
`[PROVISIONAL]`. Clearance в provisional — только knockout-скрин с
честной пометкой, что поиск по ФИПС не выполнен.

## Отличия от CFL

1. ГК ч. 4 вместо US-каркаса (таблица выше), СИПН вместо TTAB, ФИПС
   вместо USPTO
2. Пути: `~/.hermes/legal/` вместо `~/.claude/plugins/config/`
3. Open-данные по ТЗ — ФИПС открытые реестры [MCP нет!]: web_search с
   тегом `[verify]` и обязательной ссылкой на номер регистрации;
   официального API ФИПС нет
4. Slack → Telegram (Hermes gateway)
5. Патентные поверенные — обязательный этап по большинству действий
   (заявки, споры) — плагин только готовит черновики
