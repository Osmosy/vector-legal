# /related-skills-surfacer

1. Загрузить `~/.hermes/legal/legal-builder-hub/CLAUDE.md` → practice profile.
2. Прогнать workflow ниже.
3. Проверить, чем пользователь занимался в других плагинах. Матчить против
   реестров.
4. Предложить: «Вы заняты X — у community есть связанный навык Y».

---

## Purpose

Community мог построить то, что вы собираетесь строить. Этот навык замечает
и упоминает — один раз, коротко, ненавязчиво.

## Как запускается

Сурфейсит связанные community-навыки после задачи. Пользователь может
вызвать напрямую («что ещё есть для X?») или подключить в другие плагины —
hook-паттерн требует, чтобы плагин-сосед вызывал этот навык в конце задачи,
чего по умолчанию нет. Без hook-обвязки — прямой вызов.

Соседний плагин может включить лёгкую проверку в конце задачи:

> «legal-builder-hub нашёл community-навык, который может помочь с таким:
> [имя] — [одна строка]. Посмотреть?»

## Загрузка контекста

`~/.hermes/legal/legal-builder-hub/CLAUDE.md` → practice profile,
установленные навыки (не предлагать уже установленное).
Кэш реестров от registry-browser (`registry-cache.json`).

## Матч

По описанию задачи (чем пользователь только что занимался) найти навыки
реестров, совпадающие с ней:

- Keyword-пересечение задачи и описаний навыков
- Фит practice profile (не предлагать litigation-навыки транзакционному
  юристу; учитывать фильтр юрисдикции — RU-практике сначала предлагать
  RU-адаптированные навыки Vector Legal, потом иностранные с пометкой
  «нужна адаптация»)
- Не установлено уже

**Порог:** сурфейсить только при сильном матче. Слабые матчи — шум. Лучше
не сурфейсить ничего, чем раздражать.

## Вывод

При сильном матче:

> 💡 У community есть навык для этого: **[имя]** из [реестра] —
> «[description]». `skill-installer [имя]` — чтобы попробовать.

Если сильного матча нет: тихо. Никакого вывода. Не объявлять «я ничего
не нашёл».

## Лимит частоты

Не сурфейсить один навык дважды. Если пользователь не установил его в первый
раз — он его увидел и решил «нет». Трекать dismissals в
`~/.hermes/legal/legal-builder-hub/surfaced.json`:

```json
{
  "skill-name": {"surfaced_at": "YYYY-MM-DD", "source_task": "...", "dismissed": true}
}
```

## Пользовательский контроль

По `~/.hermes/legal/legal-builder-hub/CLAUDE.md` → уведомления о новых
навыках:
- **Все:** сурфейсить любой матч
- **По practice profile:** фильтровать по профилю (дефолт)
- **Нет:** навык выключен

## Чего этот навык НЕ делает

- Ничего не устанавливает.
- Не прерывает задачу. Сурфейс — в конце задачи, не в середине.
- Не нудит. Одно упоминание на навык — ever.
