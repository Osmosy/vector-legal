# /uninstall

Прогнать workflow `uninstall` из референс-навыка `skill-manager` против
названного навыка. Загрузить `skill-manager` перед содержательной работой.

Правила безопасности:

1. **Убирать только community-навыки, установленные через этот хаб.**
   Проверка по `~/.hermes/legal/legal-builder-hub/install-log.yaml` и
   таблице установленного starter pack в профиле хаба. Нет записи — отказ
   с объяснением (навык мог быть инкорпорирован вне хаба; тогда управление —
   руками через skill_manage или редактирование).
2. **Никогда не убирать навык доменного плагина Vector Legal.** 9 доменных
   плагинов off-limits. Если названный навык резолвится внутрь одного из
   них — отказ. Для первого-party управления используется репозиторий
   vector-legal, а не этот навык.
3. **Подтверждать перед файловыми операциями.** Показать пользователю
   каждый путь. Продолжать только по явному «да».
4. **Архивировать по умолчанию, не удалять.** Каталог навыка移送 в
   `~/.hermes/legal/legal-builder-hub/archive/[навык]-[дата]/` с
   `RESTORE.md` (откуда, версия, чем восстановить). Полноценное удаление —
   только по явному вторичному выбору «удалить насовсем» в подтверждении.
5. **Снимать регистрацию Hermes.** Если навык был инкорпорирован через
   `skill_manage` (в логе есть `skill_manage_action`), uninstall снимает
   регистрацию вызовом `skill_manage` delete — иначе файлы уйдут в архив,
   а дисковери продолжит показывать призрака.
6. **Логировать uninstall.** Добавить в `install-log.yaml` запись
   `action: uninstall` с timestamp и путём архива — audit trail сохраняется.

Конфиг в `~/.hermes/legal/<plugin>/` по умолчанию НЕ удаляется — он может
пригодиться при реустановке. Удаление конфига — только по явному запросу
пользователя.

Если пользователь хочет остановить навык, но сохранить файлы активными для
быстрого re-enable (например, сохранить конфиг и настройки), предложить
`disable` вместо uninstall.

> Детальные uninstall/disable/re-enable workflows — в референс-навыке
> `skill-manager` — загрузить его перед содержательной работой.
