# Legal Clinic — Юридическая клиника (Vector Legal)

Адаптация [claude-for-legal/legal-clinic](https://github.com/anthropics/claude-for-legal)
(Anthropic, Apache-2.0) под российское право и Hermes Agent.

## Что это

Плагин для **юридических клиник** — институтов, где студенты-юристы под
контролем супервизора (квалифицированного юрработника) оказывают бесплатную
юридическую помощь людям, которые не могут позволить себе юриста: жилищные
споры, семейные дела, защита прав потребителей, миграционные вопросы,
трудовые споры, пенсии и социальное обеспечение.

Правовая рамка РФ: **Федеральный закон № 324-ФЗ от 21.11.2011 «О бесплатной
юридической помощи в Российской Федерации»** — юридические клиники оказывают
помощь в рамках клинического обучения (ст. 15), с гражданином заключается
соглашение (ст. 17); категории граждан с правом на помощь закреплены
законом (ст. 20) и программами субъектов РФ. `[model knowledge — verify]`

**Каждый выход — черновик для разбора студентом и проверки супервизором —
помечен, поставлен в очередь, залогирован.** Плагин scaffolding'ит работу,
студент её осмысливает, супервизор подписывает. **Ничто не уходит к клиенту,
в суд или ведомство без подписи супервизора** — это жёсткое правило всего
плагина (см. ⛔ SUPERVISOR-GATE в `CLAUDE.md`).

## ⚠️ Юридический дисклеймер (канонический)

**Всё, что производит плагин, — черновик для проверки юристом.** Не юридическая
консультация, не правовое заключение, не замена юриста. Каждый документ
проходит проверку супервизором клиники до выхода за пределы клиники.
Источники указываются явно; цитаты из модельных знаний помечены
`[model knowledge — verify]` и проверяются по первоисточникам
(pravo.gov.ru, КонсультантПлюс/Гарант).

## Problem this solves

Клиника структурно ограничена по ресурсам: супервизор ведёт 5–10 студентов,
у каждого студента несколько дел параллельно с учёбой, вся команда меняется
каждый семестр. Первичный приём, черновики, отправные точки для поиска,
статусы — съедают часы, которые могли бы идти на консультирование клиентов.
Результат — лист ожидания и люди, которые не дождались.

Плагин удешевляет всё *вокру́г* юрработы, сохраняя саму юрработу за студентом.

## Кто использует

| Роль | Что запускает | Что получает |
|---|---|---|
| **Супервизор** (квалифицированный юрработник клиники) | `cold-start-interview` (один раз), `supervisor-review-queue`, `build-guide` | Настроенный профиль клиники; проверенная работа студентов |
| **Студент** | `ramp` (начало семестра), затем `client-intake` → `draft` / `memo` / `research-start` / `status` / `client-letter` / `deadlines` | Отправные точки — никогда не финальный work product |

## Порядок работы (семестровый цикл)

```
Начало семестра:   cold-start-interview (профиль) → ramp (онбординг студентов)
В течение недели:  client-intake → memo → research-start → draft
                   client-letter (простой язык) → client-comms-log → deadlines
                   status клиенту | супервизору | суду
Постоянно:         supervisor-review-queue → подпись → отправка
Конец семестра:    semester-handoff → передача дел новому набору
```

## Структура

```
legal-clinic/
├── CLAUDE.md                          # Шаблон practice profile (заполняет cold-start)
├── README.md                          # Этот файл
└── skills/
    ├── cold-start-interview/          # Супервизор — настройка клиники один раз
    ├── build-guide/                   # Супервизор — гайд по категории дел (intake, педагогика, гейты)
    ├── ramp/                          # Студенты — семестровый онбординг + учебные упражнения
    ├── customize/                     # Точечная правка профиля без переинтервью
    ├── client-intake/                 # Первичный приём: 152-ФЗ согласие, категории ФЗ-324, триаж
    ├── memo/                          # Заключение по делу: каркас + процессуальная позиция (ГК/ТК/КоАП)
    ├── research-start/                # Дорожная карта поиска: pravo.gov.ru, kad.arbitr, обзоры ВС
    ├── draft/                         # Черновики документов: суды, ГИТ, прокуратура, Роспотребнадзор
    ├── client-letter/                 # Рутина + принцип простого языка: письма для людей без юр-образования
    ├── status/                        # Статус по делу: клиент (простой язык) | супервизор | суд
    ├── deadlines/                     # Калькуляция и учёт сроков: АПК/ГПК/КАС + трудовые (ст. 392 ТК)
    ├── client-comms-log/              # Журнал коммуникаций по делу (append-only)
    ├── supervisor-review-queue/       # Очередь супервизора с тегами уровня риска
    └── semester-handoff/              # Семестровая отчётность и передача дел
```

Отклонение от CFL (2 deprecated-навыка не переносятся): в CFL v2 навыки
`plain-language-letters` (разделён на `client-letter` и `status client`) и
`form-generation` (свёрнут в `/draft`) депрекированы и существуют только как
redirect-заглушки. Здесь они **как каталоги не переносятся**; redirect-поведение
задокументировано в этом README. Принцип писем на простом языке для людей без
юридического образования — ядро мандата юр. клиники — закреплён явно в
`client-letter` и в клиентском режиме `status`, а также в plain-language
стандартах `CLAUDE.md`. Итого: **14 активных навыков**.

## Быстрый старт

```
cold-start-interview          # 2 мин quick / 15 мин full — пишет practice profile
client-intake                 # Первичный приём гражданина
client-letter                 # Письмо клиенту на простом языке
supervisor-review-queue       # Очередь супервизора → подпись
```

До cold-start все навыки работают в **provisional mode**: generic дефолты
(право РФ, категории ФЗ-324 по умолчанию) с меткой `[PROVISIONAL]`.

## Practice profile

Конфигурация живёт в `~/.hermes/legal/legal-clinic/CLAUDE.md` (Hermes-нативный
путь; в Claude-версии — `~/.claude/plugins/config/...`). Шаблон: `CLAUDE.md`
в корне плагина. Профиль содержит:

- **Тип клиники** (при вузе / студенческая консультация / центр НКО)
- **Супервизорская модель** — кто именно подписывает исходящие документы
  (ФИО замещающего тоже), механика: очередь / флаги / лёгкий режим
- **Категории дел** (жилищные / семейные / потребительские / миграционные /
  трудовые / соцобеспечение — по ФЗ-324 ст. 15-17 и региональной программе)
- **Эскалации** — кому эскалируется конфликт интересов, этические вопросы,
  превышение мандата клиники
- **Header-правила** выходных документов
- **⛔ SUPERVISOR-GATE: НИЧТО не уходит к клиенту без подписи супервизора** —
  вынесено на первое место в профиле, читается каждым навыком до работы

### Право Российской Федерации (замены против US-версии)

| CFL (US) | Vector Legal (RU) |
|---|---|
| ABA Model Rules, Formal Op. 512 | Этические предусловия клиники: положение о клинике, 152-ФЗ (согласия, конфиденциальность), контроль квалифицированного юрработника (ФЗ-324 ст. 15); ИИ-дислоужр клиенту — по решению клиники, документируется |
| Student practice rule (напр. Cal. R. Ct. 9.42) | Студент не выступает самостоятельно: работа под контролем супервизора (ФЗ-324 ст. 15: клиническое обучение под контролем квалифицированных юрработников) |
| Work product / privilege (FRCP 26(b)(3)) | Адвокатская тайна (ст. 8 ФЗ-63) — только для адвокатов; конфиденциальность клиники по положению + 152-ФЗ; честный гриф без ложной защиты |
| Westlaw / CourtListener / Descrybe | pravo.gov.ru (официальный портал НПА), КонсультантПлюс/Гарант (нет MCP → web_search + `[verify]`), kad.arbitr.ru, sudrf.ru, обзоры ВС РФ |
| State courts / county rules | Суды общей юрисдикции (мировые/районные) + ГАС «Правосудие»; арбитраж — только если категория дела того требует (для клиники обычно нет) |
| Clio case management | Локальные файлы на диске; интеграции по профилю ⚪ |

## Очные навыки против суд-байндинг

Исходящее в суд/ведомство/клиенту → всегда очередь супервизора → подпись →
отправка. Внутреннее (черновики, заключения, roadmap'ы, статусы супервизору)
работает без очереди, но несёт стандартные пометки.

## Отличия от CFL

1. Право РФ вместо US (таблица выше), юрисдикция (регион, суды) в профиле — обязательное поле
2. Supervisor-gate ужесточён: в CFL «lighter-touch» мог обходиться без ворот; здесь **подпись супервизора обязательна всегда**, настраивается только механика (очередь/флаги)
3. Пути: `~/.hermes/legal/legal-clinic/` вместо `~/.claude/plugins/config/`
4. research-start работает в открытый контур РФ (pravo.gov.ru, КонсультантПлюс free, kad.arbitr, sudrf.ru, обзоры ВС) вместо Westlaw/CourtListener
5. `plain-language-letters` — **не перенесён** как отдельный навык: в CFL v2
   он депрекирован и разделён на `client-letter` (рутина) и `status client`
   (содержательные апдейты). Принцип простого языка для людей без
   юр-образования закреплён в обоих навыках и в plain-language стандартах
   профиля
6. Депрекационные навыки CFL `plain-language-letters` и `form-generation` —
   redirect-заглушки на `/draft`, `/client-letter` + `/status client`; здесь
   как каталоги не переносятся (см. п. 5 и примечание у дерева структуры)
7. Интеграции: Clio/Google Drive → локальное хранилище + Telegram (Hermes gateway); Slack → Telegram
8. Семестровая терминология: осенний/весенний семестр, учебная практика в 4–5 курсах/магистратуре
