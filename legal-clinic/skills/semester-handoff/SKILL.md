# /semester-handoff — передача дел между семестрами

1. Загрузить `~/.hermes/legal/legal-clinic/CLAUDE.md` → профиль клиники,
   даты семестра, супервизорская модель.
2. Загрузить `~/.hermes/legal/legal-clinic/deadlines.yaml` и
   `~/.hermes/legal/legal-clinic/client-comms/[case-id]/log.md` по делам.
3. Использовать workflow ниже.
4. Взять список активных дел как вход (спросить, если центрального списка
   нет). Сопоставить уходящих → входящих.
5. Сгенерировать хэндов-мемо по делу →
   `~/.hermes/legal/legal-clinic/handoffs/[семестр]/[case_id].md`.
6. Сгенерировать сводку когорты →
   `~/.hermes/legal/legal-clinic/handoffs/[семестр]/_summary.md`.
7. Маршрутизация по модели супервизии — очередь / флаги / лёгкий режим.

# Semester Handoff

## Назначение

Каждый семестр клиника теряет всю команду и собирает заново. `ramp` решает
половину проблемы — онбордит входящих. Этот навык решает вторую половину —
выпроваживает уходящий набор с хэндов-мемо, которые фиксируют, что входящему
нужно знать по каждому активному делу.

Без этого знание дела уходит вместе со студентом. Новый студент стартует с
файла дела и intake-резюме, которых всегда мало. Две недели уходят на
повторное освоение, прежде чем студент снова полезен. Клиент переживает
это как регресс — звонки без ответов, повторные вопросы.

## Аудитория

Супервизор или уходящие студенты. Супервизор запускает, чтобы организовать
выпуск всей когорты; отдельные студенты — по своим делам при переходе
посреди семестра.

## Load context

- `~/.hermes/legal/legal-clinic/CLAUDE.md` → профиль клиники, семестр,
  категории, супервизорская модель
- `~/.hermes/legal/legal-clinic/deadlines.yaml` → активные сроки по делам
- `~/.hermes/legal/legal-clinic/client-comms/[case-id]/log.md` → история
  коммуникаций
- Файлы дел / intake-резюме клиники
- Ростер студентов — кто чем владеет на момент передачи

## Workflow

### Шаг 1: Дела и исполнители

- Собрать все активные дела (из intake-записей + case_ids из
  `deadlines.yaml` + папок client-comms)
- По каждому: кто текущий студент-исполнитель? Остаётся или уходит?
- Сопоставить: уходящий → входящий (если известен; иначе «TBD — распределит
  супервизор»)

Если клиника не ведёт центральный список активных дел — навыку нужен один
вход: перечень активных дел. Спросить. Не угадывать.

### Шаг 4: Проверка супервизором (по модели)

Передача дела или его закрытие — consequential action. Ворота —
SUPERVISOR-GATE из профиля (подпись супервизора обязательна независимо от
модели). Мемо о закрытии дела всегда получают подпись супервизора до того,
как дело отмечено закрытым в хэндов-документе.

По профилю:

- **Формальная очередь:** каждое хэндов-мемо проходит очередь до передачи
  входящему. Супервизор одобряет, правит или возвращает.
- **Флаги:** мемо помечены «СВЕРЬСЯ С [СУПЕРВИЗОРОМ] ДО ОПОРЫ» — супервизор
  проверяет неформально, студент сам несёт на сверку.
- **Лёгкий режим:** мемо несут стандартную этикетку; супервизор проверяет
  через существующую структуру. Мемо о закрытии всё равно идут супервизору.

### Шаг 5: Передать

После проверки мемо живут в
`~/.hermes/legal/legal-clinic/handoffs/[семестр]/[case_id].md`. Входящий
студент читает их в ramp в начале следующего семестра — ramp должен поднять
мемо по делам, за которые студент берётся.

## Интеграция

- **`ramp`:** в начале семестра читает `handoffs/[последний-семестр]/` и
  показывает мемо по делам входящего студента.
- **`deadlines`:** даёт секцию сроков в каждом мемо.
- **`client-comms-log`:** даёт сводку коммуникаций.
- **`supervisor-review-queue` (при формальной модели):** мемо маршрутизируются
  в очередь на одобрение.

## Что этот навык НЕ делает

- **Не закрывает дела.** Хэндовер — для дел, переходящих следующей когорте.
  Дела, закрывающиеся в конце семестра, получают финальное внутреннее мемо
  (`status supervisor`) в файл и отметку «закрыто» в хэндов-документе.
- **Не распределяет входящих.** Распределяет супервизор. Навык фиксирует
  назначение, не выбирает.
- **Не строит хэндовы без данных клиники.** Нужен перечень активных дел на
  входе. Нет списка — навык показывает пробел как блокер, а не выдумывает.
- **Не заменяет разговор.** Мемо — документ. Уходящий студент должен ещё и
  поговорить с входящим — мемо фиксирует факты; разговор передаёт суждение
  и контекст отношений, которых в мемо не удержать.
