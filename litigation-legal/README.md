# Litigation Counsel — Споры и судебная работа (Vector Legal)

Адаптация [claude-for-legal/litigation-legal](https://github.com/anthropics/claude-for-legal)
(Anthropic, Apache-2.0) под процессуальное право Российской Федерации
(АПК/ГПК, ГК, НК) и Hermes Agent.

## Что это

Инхаус-литигация и процессуальная кухня: единый intake для каждого нового дела
(арбитражный процесс или суд общей юрисдикции), портфельный журнал `_log.yaml`,
досудебный порядок (претензионная работа — где он **обязателен** и с какими
сроками), хронология, которая превращается в доказательственную базу, таблица
требований (основание + доказательства + расчёт), черновики процессуальных
документов и триаж входящих: претензии, судебные запросы, истребование
доказательств, налоговые истребования.

Выход — документ, который юрист проверяет за один проход, и запись в журнале,
которую портфель не теряет.

## ⚠️ Юридический дисклеймер (канонический)

**Всё, что производит плагин, — черновик для проверки юристом.** Не процессуальный
документ, не юридическая консультация, не замена юриста. Процессуальные документы
подписывает и подаёт человек; ошибки в процессуальных сроках и реквизитах
невосполнимы (ст. 125, 126 АПК; ст. 131, 132 ГПК). Источники указываются явно.

## Структура

```
litigation-legal/
├── CLAUDE.md   # Шаблон practice profile → копируется в CLAUDE.md
├── README.md                      # Этот файл
└── skills/                        # 19 навыков
    ├── cold-start-interview/      # Интервью → пишет practice profile
    ├── customize/                 # Точечная правка профиля
    ├── matter-workspace/          # Рабочие пространства дел (для firm/мультиклиент)
    ├── matter-intake/             # Заведение дела в картотеку (подведомственность, конфликт-чек)
    ├── matter-update/             # Журнал событий по делу
    ├── matter-briefing/           # Брифинг по одному делу перед заседанием/звонком
    ├── matter-close/              # Закрытие дела: исход, уроки, архив
    ├── chronology/                # Хронология событий → доказательственная база
    ├── claim-chart/               # Таблица требований (основание+доказательства+расчёт)
    ├── demand-intake/             # Сбор контекста под претензию
    ├── demand-draft/              # Черновик претензии (ст. 452 ГК, ч. 5 ст. 4 АПК)
    ├── demand-received/           # Триаж входящей претензии/требования
    ├── deposition-prep/           # Допрос свидетеля (ст. 88 АПК), пояснения лиц, witness statement
    ├── legal-hold/                # Обеспечение доказательств (ст. 72 АПК), арест, сохранение данных
    ├── privilege-log-review/      # Адвокатская тайна vs КТ при передаче документов
    ├── subpoena-triage/           # Судебные запросы (ст. 66 АПК), повестки, истребования 93.1 НК
    ├── brief-section-drafter/     # Черновики процессуальных документов (ст. 125/131 АПК и др.)
    ├── portfolio-status/          # Сводка по картотеке (риски, сроки, аномалии)
    └── oc-status/                 # Статус-запросы внешним юристам; контроль счетов и бюджета
```

> **Примечание об именах.** В окружении, где собирался этот плагин, запись
> файла с именем `CLAUDE.md` заблокирована guard'ом защиты агентских
> инструкций, поэтому шаблон practice profile лежит как
> `CLAUDE.md`. При установке скопируйте его в
> `~/.hermes/legal/litigation-legal/CLAUDE.md` — навыки читают конфиг
> именно оттуда.

## Быстрый старт

```
cold-start-interview                # 10–15 мин — пишет practice profile
matter-intake "Дело А vs Мы 2026"   # Завести дело в картотеку
demand-received <файл>              # Пришла претензия — триаж
```

До cold-start все навыки работают в **provisional mode**: generic дефолты
(право РФ, арбитраж по умолчанию, претензионный порядок 30 дней по ч. 5 ст. 4
АПК) с меткой `[PROVISIONAL]` — см. ниже.

## Practice profile

Конфигурация живёт в `~/.hermes/legal/litigation-legal/CLAUDE.md` (в
Claude-версии — `~/.claude/plugins/config/...`; здесь путь Hermes-нативный).
Шаблон: `CLAUDE.md` в корне плагина. Профиль содержит:

- **Роль пользователя** (юрист / не-юрист с доступом к юристу / не-юрист) —
  определяет header выходных документов
- **Practice role** (in-house / партнёр-ассоциат фирмы / solo) — определяет
  словарь (портфель дел / caseload / client update)
- **Сторона по умолчанию** (истец / ответчик / обе) — определяет калибровку
  риска: у истца цена иска и исполнимость, у ответчика — экспозиция и резервы
- **Подведомственность и форы** (АС / СОЮ / третейские оговорки)
- **Матрица severity × likelihood**, пороги существенности, лестница
  полномочий на мировое, страховой профиль
- **Претензионный порядок** (30 дней по ч. 5 ст. 4 АПК — если договором не
  установлено иное; договор и закон побеждают)
- **House style** для процессуальных документов, эскалации, bench внешних юристов

### Право Российской Федерации (замены против US-версии)

| CFL (US) | Vector Legal (RU) |
|---|---|
| Attorney work product (FRCP 26(b)(3)) | Адвокатская тайна (ст. 8 ФЗ-63 «Об адвокатуре»); для не-адвокатов — коммерческая тайна (ФЗ-98, режим вводится фактически). Header для юриста: `КОНФИДЕНЦИАЛЬНО — АДВОКАТСКАЯ ТАЙНА` (только если готовит адвокат); иначе `КОНФИДЕНЦИАЛЬНО — ВНУТРЕННИЙ ПРАВОВОЙ АНАЛИЗ` |
| Privilege log (FRCP 26(b)(5)) | Нет privilege log как института. Замена: внутренний реестр «что передаём и под каким режимом» (адвокатская тайна / КТ / обычный документ). Суд РФ сам оценивает допустимость и относимость доказательств (ст. 71, 89 АПК) |
| Depositions (FRCP 30) | Нет depositions. Замены: допрос свидетеля (ст. 88 АПК; ст. 70 ГПК), пояснения лиц-участников (ст. 81 АПК), пояснения сторон (ст. 174, 188 ГПК), экспертиза (ст. 82 АПК). Для иностранных арбитражей (МКАС/SCC/LCIA) — witness statement |
| Subpoena (FRCP 45) | Судебные запросы и истребование доказательств (ст. 66 АПК; ст. 57 ГПК), повестки, обследование помещений; налоговые: истребование документов у самого налогоплательщика (ст. 93 НК), встречная проверка — у контрагента (ст. 93.1 НК) |
| Rule 26 scope of discovery | Относимость к делу (ст. 67, 68 АПК); доказательства истребуются через суд; «fishing expedition» процессуально невозможен — суд контролирует перечень |
| Pre-suit demand letter | Претензия. Досудебный порядок для денежных требований из договоров/сделок/неосновательного обогащения — **обязателен**: 30 календарных дней со дня направления претензии, если иные срок и (или) порядок не установлены законом или договором (ч. 5 ст. 4 АПК) |
| Statute of limitations | Ст. 196–200 ГК: 3 года общий, 10 лет объективный предел; прерывание признанием долга (ст. 203 ГК); для исков к органам власти — 3 месяца (ст. 198 АПК) |
| Appeal deadlines | Апелляция — 1 месяц (ст. 259 АПК); кассация — 2 месяца со дня вступления в силу (ст. 276 АПК); кассация/апелляция в ВС — 3 месяца (ст. 291.1, 308.3, 308.4 АПК). Аналоги ГПК: ст. 321, 376.1, 308.3 ГПК |
| ASC 450 reserves, 10-Q disclosure | РСБУ/МСФО: оценка условного обязательства (IAS 37); раскрытие — по существенности, решает бухгалтерия |
| Outside counsel hourly billing | Фикс на дело / почасовые с cap / поэтапная оплата; с адвокатом — соглашение об оказании юридической помощи (ст. 25 ФЗ-63) с существенными условиями о гонораре; контроль счетов через oc-status |
| Slack/Gmail notifications | Telegram через Hermes gateway |
| CourtListener / eDiscovery (Everlaw, Relativity) | kad.arbitr.ru (картотека АС) + sudrf.ru / ГАС «Правосудие» (дела СОЮ); официального MCP нет — web_search + `[verify]`, решения проверять на первоисточнике |

Это замены каркаса; конкретные позиции playbook — только из интервью и
реальной практики команды (как в CFL: никаких дефолтов «с потолка»).

## Подведомственность и форы

Плагин работает в трёх ветках — каждая intake переспрашивает:

- **Арбитражные суды (АС)** — экономические споры, споры с госорганами,
  корпоративные споры (ст. 225.1 АПК), банкротство. Нормы АПК. Реестры:
  kad.arbitr.ru; подача через «Мой арбитр».
- **Суды общей юрисдикции (СОЮ)** — трудовые, потребительские, семейные
  споры, частноправовые споры физлиц, приказное производство. Нормы ГПК.
  Реестры: sudrf.ru / ГАС «Правосудие»; подача через ГАС.
- **Третейские разбирательства (МКАС, РАА, SCC, LCIA)** — если есть
  действующая оговорка. Влияние: claim-chart учитывает регламент,
  deposition-prep переключается на witness statement.

Подведомственность (ст. 27–33 АПК; ст. 22–23 ГПК) intake проверяет
**обязательно**: ошибка = возврат иска (ст. 127, 128 АПК), потерянные месяцы,
риск для срока давности.

## Отличия от CFL

1. Право и процесс РФ вместо US (таблица выше); АПК/ГПК ветки в каждом
   процессуальном скилле
2. Пути: `~/.hermes/legal/` вместо `~/.claude/plugins/config/`
3. Интеграции: eDiscovery (Everlaw/Relativity) → локальное хранилище +
   реестр + ручные пути (объём файлов в РФ-практике обычно меньше)
4. CourtListener → kad.arbitr.ru + sudrf.ru / ГАС «Правосудие»; готового
   MCP нет — web_search + пометка `[verify]`
5. КонсультантПлюс/Гарант — MCP нет; первоисточник — pravo.gov.ru
6. Slack-уведомления → Telegram через Hermes gateway
7. Нет аналога deposition → см. таблицу replacement
8. Нет privilege log → см. privilege-log-review (режимы защиты вместо привилегии)
