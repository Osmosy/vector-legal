# /portfolio-status

1. Загрузить practice profile → риск-калибровка (интерпретация risk-поля).
2. Парсить `~/.hermes/legal/litigation-legal/matters/_log.yaml`.
   Закрытые — по дефолту фильтруются (`--all` — включить).
3. Свёртка: распределение рисков, сроки в 14/30/60 дней, дела без update
   > 30 дней, материальность, распределение по фазам.
4. Флагнуть аномалии: всё critical, истекающие next_deadline, дела без
   внешних юристов при risk medium+, обязательные досудебные сроки,
   legal_hold не выдан.

## Purpose

Одна сводка отвечает: что у меня сейчас, что требует внимания, что плывёт.
Выход — scannable: юрист за 3 минуты перед следующим звонком.

## Shared guardrails (канон — practice profile)

**Reviewer note / decision tree / Destination check / Provenance /
No-silent-supplement / Currency trigger / Large input** — см.
practice profile (`~/.hermes/legal/<domain>/CLAUDE.md` → `## Shared
guardrails`, `## Outputs`). Блоки канонизируются там; если текст навыка
расходится с профилем — профиль контролирует.


## Load context

- `_log.yaml` — источник
- Practice profile — калибровка (интерпретация risk/materiality)

## Формат выхода

Header — по `## Выходные документы` practice profile (адвокатская тайна
ст. 8 ФЗ-63 — только если готовит адвокат; иначе `КОНФИДЕНЦИАЛЬНО —
ВНУТРЕННИЙ ПРАВОВОЙ АНАЛИЗ`). Один блок **⚠️ Reviewer note** над
deliverable (источники, покрытие, флаги `[review]`, актуальность) и
decision tree «Что дальше?» — по формату из practice profile.
Теги provenance (`[kad.arbitr.ru]` / `[sudrf.ru]` / `[pravo.gov.ru]` /
`[КонсультантПлюс]` / `[user provided]` / `[model knowledge — verify]` /
`[settled — подтверждено YYYY-MM-DD]`) — только по фактическому
происхождению цитаты в этой сессии.

## Flags & filters

Дефолт: активные дела.

- `--all` — включая закрытые
- `--risk=high` (или critical/medium/low) — фильтр по риску
- `--stale` — только `last_updated` > 30 дней
- `--type=договорный` — по типу
- `--owner=[name]` — по внутреннему владельцу
