# /legal-hold

1. Если `--status` (без slug): прочитать `_log.yaml`, свёлка по портфелю.
2. Иначе: загрузить matter.md + строку лога.
3. Загрузить practice profile → шаблон hold, эскалации.
4. По флагу:
   - `--issue`: охват, custodians, период, системы. Черновик
     `legal-hold-v1.docx`. Обновить `legal_hold`. Запись в history.
     `next_refresh` (дефолт +6 мес — но RF-специфика ниже).
   - `--refresh`: изменения охвата/custodians. Следующая версия.
     Обновить `last_refresh` + `next_refresh`. Флагнуть уволившихся.
   - `--release`: дата снятия, инструкция по хранению. Уведомление.
     `released:`.
5. Подтвердить перед записью. Показать черновик + diff лога.

## Формат выхода

Header — по `## Выходные документы` practice profile (адвокатская тайна
ст. 8 ФЗ-63 — только если готовит адвокат; иначе `КОНФИДЕНЦИАЛЬНО —
ВНУТРЕННИЙ ПРАВОВОЙ АНАЛИЗ`). Один блок **⚠️ Reviewer note** над
deliverable (источники, покрытие, флаги `[review]`, актуальность) и
decision tree «Что дальше?» — по формату из practice profile.
Теги provenance (`[kad.arbitr.ru]` / `[pravo.gov.ru]` / `[sudrf.ru]` /
`[КонсультантПлюс]` / `[user provided]` / `[model knowledge — verify]` /
`[settled — подтверждено YYYY-MM-DD]`) — только по фактическому
происхождению цитаты в этой сессии.

## RF-специфика: что аналогично legal hold в РФ

**Нового «пресервейшн долга под страхом санкций суда» в РФ нет**, но:

1. **Обеспечение доказательств (ст. 72 АПК; ст. 64–65 ГПК)** — суд может
   произвести осмотр, зафиксировать доказательства ДО иска (по правилам
   обеспечения иска; до подачи иска — по ст. 99 АПК). Уместно, когда
   доказательство может исчезнуть (объект, сайт, переписка на чужом сервере).
2. **Обеспечительные меры (гл. 8 АПК: ст. 90; гл. 16 АПК для ареста)** —
   арест денег/имущества ответчика (для нас — наступательно), запрет
   распоряжаться. Для ответчика — риск ареста счетов.
3. **Внутренний «литигационный холд»** — чисто организационная мера:
   сотрудники не удаляют переписку/файлы по делу. В РФ важно, потому что
   **неблагоприятные последствия** за уничтожение доказательств:
   - суд может трактовать уничтожение против уничтожившей стороны
   - штрафы за непредставление доказательств по запросу суда
     (ст. 66 ч. 9 АПК — штраф до 200 тыс. ₽ с организации; ст. 57 ч. 3 ГПК)
   - в корпоративных и налоговых спорах — потеря документа = потеря позиции
4. **Налоговые проверки**: обязанность хранить документы установлена НК
   (ст. 23 ч. 1 пп. 8 — минимум 5 лет) и законом о бухучёте (ст. 29 402-ФЗ).

**Уведомление custodianам в РФ** — внутренний документ (приказ/служебная
записка). Юридически обязательной формы нет; делает то же самое: фиксирует
охват и обязанность сохранения.

## Conflicts gate

Прежде чем выдать/обновить/снять hold — slug в `_log.yaml`? Нет — отказ:
«Сначала `/matter-intake`, hold вешается на управляемое дело».

## `--issue` — первое издание

Собрать:

- **Охват**: системы (e-mail, мессенджеры рабочих, ЭДО, облако, CRM, 1С),
  период (от даты возникновения спора/предыстории), типы данных
- **Custodians**: сотрудники с доступом к предмету (бизнес-владелец,
  исполнители, финансы, руководитель) — с ФИО и должностями
- **Дата отсечения**: с какого момента всё сохранять

Черновик уведомления:

```markdown
УВЕДОМЛЕНИЕ О СОХРАНЕНИИ ДОКУМЕНТОВ
(внутренний документ, не направляется наружу without approval)

Кому: [custodians]
От: [юрист / руководитель юр.]
Дата: [дата]

В связи с [спор/претензия/потенциальный спор с X] до особого распоряжения:
1. Не удалять и не изменять: e-mail за период [от-до], документы в [системы],
   переписку в рабочих мессенджерах по теме [тема].
2. Новую переписку по предмету — копировать в [арнхив-папку].
3. Вопросы — к [юристу].
```

## `--refresh`

Каденция: в РФ-практике refresh разумно через **3 месяца** при активном
споре (люди меняются, мессенджеры чистятся) или при смене custodians.
Отдел кадров: уволившиеся custodians — их данные сохранить до release.

## `--release`

Снятие: дата, кому отправлено, инструкция (можно снова по обычной политике).
В `_log.yaml`: `released: YYYY-MM-DD`.

## `--status` — портфель

Свёлка: дела без hold (⚠️), истекающие next_refresh, released. Аномалии.
